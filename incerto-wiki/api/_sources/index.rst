Incerto Python API
==================

The ``incerto`` package contains the reusable Python objects used by the
Incerto Wiki examples: probability distributions, tail estimators, summary
statistics, and plotting helpers.

This API reference is generated from source docstrings with Sphinx. The main
Incerto Wiki remains a Jupyter Book v2 / MyST site; this reference is built as
a companion static site under ``/api/``.
