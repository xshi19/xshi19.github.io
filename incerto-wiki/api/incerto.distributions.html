incerto.distributions#

Probability distributions used by Incerto Wiki examples.

The classes in this module migrate the useful distributions from legacy/src/distributions.py into the installable package. They follow the scipy.stats.rv_continuous pattern so content pages can use familiar methods such as pdf, cdf, sf, ppf, rvs, and stats.

class incerto.distributions.double_pareto_gen(momtype=1, a=None, b=None, xtol=1e-14, badvalue=None, name=None, longname=None, shapes=None, seed=None)[source]#

Bases: rv_continuous

Symmetric double Pareto distribution.

The distribution is formed by taking a Pareto random variable Y with lower cutoff 1 and shape alpha, then assigning the sign of Y - 1 with equal probability. Its density is

\[f(x; \alpha) = \frac{\alpha}{2}(1 + |x|)^{-(\alpha + 1)}.\]
Parameters:

alpha – Positive Pareto tail exponent. Smaller values produce heavier tails.

class incerto.distributions.pareto_type1_gen(momtype=1, a=None, b=None, xtol=1e-14, badvalue=None, name=None, longname=None, shapes=None, seed=None)[source]#

Bases: rv_continuous

Pareto Type I distribution with unit lower cutoff.

The canonical distribution has survival function sf(x, alpha) = x ** (-alpha) for x >= 1. Use SciPy’s standard scale keyword to set a lower cutoff x_m other than 1.

Parameters:

alpha – Positive Pareto tail exponent. The mean is finite only for alpha > 1 and the variance only for alpha > 2.

class incerto.distributions.simple_normal_mixture_gen(momtype=1, a=None, b=None, xtol=1e-14, badvalue=None, name=None, longname=None, shapes=None, seed=None)[source]#

Bases: rv_continuous

Equal-weight mixture of two centered normal distributions.

The component variances are 1 + a and 1 - a. The continuous distribution requires 0 <= a < 1; at a = 1 one component degenerates at zero and no longer has an ordinary density.

class incerto.distributions.univariate_variance_gamma_gen(momtype=1, a=None, b=None, xtol=1e-14, badvalue=None, name=None, longname=None, shapes=None, seed=None)[source]#

Univariate variance-gamma distribution.

Parameters follow the legacy notebook convention: alpha controls tail decay, beta controls skew, and lam is the gamma shape parameter. The parameter domain is alpha > abs(beta) and lam > 0.
