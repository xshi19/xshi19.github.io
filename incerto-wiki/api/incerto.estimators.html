incerto.estimators#

Tail-index estimators and finite-sample diagnostics.

incerto.estimators.hill_alpha_estimator(x, k)[source]#

Return the reciprocal Hill estimate of the Pareto tail exponent.

Parameters:

  • x (ArrayLike) – Positive observations from a right-tail sample.

  • k (int) – Number of upper order statistics to use.

Returns:

Tail-exponent estimate alpha_hat = 1 / xi_hat. If the selected upper order statistics have zero log spacing, the result is numpy.inf.

Return type:

float

incerto.estimators.hill_estimator(x, k)[source]#

Return the Hill estimate of the extreme-value index xi.

Parameters:

  • x (ArrayLike) – Positive observations from a right-tail sample.

  • k (int) – Number of upper order statistics to use. Must satisfy 1 <= k < len(x).

Returns:

Hill estimate xi_hat. For Pareto-type tails with exponent alpha, xi = 1 / alpha.

Return type:

float

Raises:

  • ValueError – If observations are not one-dimensional, finite, and positive, or if k is outside the valid order-statistic range.

  • TypeError – If k is not an integer.

incerto.estimators.hill_stability(x, k_values=None, *, num=100)[source]#

Return Hill estimates across a range of upper order statistics.

Parameters:

  • x (ArrayLike) – Positive observations from a right-tail sample.

  • k_values (Iterable[int] | ArrayLike | None) – Optional integer values of k to evaluate. If omitted, use a logarithmically spaced grid from 1 to roughly len(x) / 3.

  • num (int) – Number of grid points to request when k_values is omitted.

Returns:

Dictionary with "k", "xi", and "alpha" arrays. "k" is stored as floating point so the result can be passed directly to NumPy and plotting functions with the other arrays.

Return type:

dict

incerto.estimators.max_to_sum_ratio(x, axis=None)[source]#

Return the share of a nonnegative sum contributed by its maximum.

Parameters:

  • x (ArrayLike) – Nonnegative observations.

  • axis (int | None) – Axis along which to compute the ratio. When None, compute over the flattened input.

Returns:

max(x) / sum(x) along the requested axis.

Return type:

float or numpy.ndarray

Raises:

ValueError – If observations are negative, non-finite, or sum to zero along the requested axis.

incerto.estimators.mean_excess(x, thresholds, *, min_exceedances=1)[source]#

Return the empirical mean excess above each threshold.

Parameters:

  • x (ArrayLike) – One-dimensional observations. The statistic is usually applied to nonnegative losses or positive right-tail observations.

  • thresholds (ArrayLike) – Threshold values u. For each threshold, the function averages x - u over observations satisfying x > u.

  • min_exceedances (int) – Minimum number of observations above a threshold required to report a finite mean excess. Thresholds with fewer exceedances return numpy.nan for "mean_excess".

Returns:

Dictionary with "threshold", "mean_excess", and "exceedances" arrays.

Return type:

dict

Raises:

ValueError – If observations or thresholds are not finite one-dimensional arrays, or if min_exceedances is less than one.

incerto.estimators.running_mean(x, axis=None)[source]#

Return cumulative arithmetic means along an axis.

Parameters:

  • x (ArrayLike) – Input observations.

  • axis (int | None) – Axis along which to compute cumulative means. When None, compute over the flattened input.

Returns:

Cumulative means with the same shape as the input along axis.

Return type:

numpy.ndarray
