incerto.figures#

Figure styling helpers for Incerto Wiki examples.

incerto.figures.savefig(fig, path, **kwargs)[source]#

Save a figure with Incerto defaults.

Parameters:

  • fig (Figure) – Figure to save.

  • path (str | Path) – Output path.

  • **kwargs (Any) – Additional keyword arguments passed to Figure.savefig.

Returns:

The resolved path supplied to Matplotlib.

Return type:

pathlib.Path

incerto.figures.set_theme(*, scale=1.0)[source]#

Apply the Incerto Matplotlib theme.

Parameters:

scale (float) – Multiplicative scale for text and marker sizes. Use the default for ordinary concept-page figures.

Raises:

ValueError – If scale is not positive.

Return type:

None

incerto.figures.style_axes(axes, *, grid_axis='y', legend=True)[source]#

Apply final Incerto styling to one or more axes.

Parameters:

  • axes (Axes | Iterable[Axes]) – A Matplotlib Axes instance or iterable of axes.

  • grid_axis (str) – Which major grid to show: "x", "y", "both", or "none".

  • legend (bool) – When true, remove legend frames from existing legends.

Returns:

The styled axes, matching the input shape as closely as practical.

Return type:

matplotlib.axes.Axes or list[matplotlib.axes.Axes]
