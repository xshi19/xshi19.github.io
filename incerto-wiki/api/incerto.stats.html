incerto.stats#

Statistical helper functions used by Incerto Wiki examples.

incerto.stats.mean_absolute_deviation(x, axis=None)[source]#

Return mean absolute deviation scaled to match normal standard deviation.

The raw mean absolute deviation is centered at the arithmetic mean. The multiplier sqrt(pi / 2) makes the value equal to sigma for a Gaussian N(mu, sigma**2) distribution.

Parameters:

  • x (ArrayLike) – Input observations.

  • axis (int | None) – Axis along which to compute the statistic. When None, compute over the flattened input.

Returns:

Scaled mean absolute deviation.

Return type:

float or numpy.ndarray

incerto.stats.median_absolute_deviation(x, axis=None)[source]#

Return median absolute deviation scaled to match normal standard deviation.

The raw median absolute deviation is centered at the median. Dividing by Phi^{-1}(0.75) makes the value equal to sigma for a Gaussian N(mu, sigma**2) distribution.

Parameters:

  • x (ArrayLike) – Input observations.

  • axis (int | None) – Axis along which to compute the statistic. When None, compute over the flattened input.

Returns:

Scaled median absolute deviation.

Return type:

float or numpy.ndarray

incerto.stats.normal_peak_shoulder_tail(mu=0.0, sigma=1.0)[source]#

Return normal scale-curvature boundaries for tail diagnostics.

The four returned points split a symmetric normal density into left tail, left shoulder, peak, right shoulder, and right tail regions under the scale-perturbation diagnostic used in the Chapter 4 notes.

Parameters:

  • mu (float)

  • sigma (float)

Return type:

ndarray[tuple[Any, …], dtype[float64]]

incerto.stats.t_peak_shoulder_tail(df, mu=0.0, sigma=1.0)[source]#

Return Student-t scale-curvature boundaries for tail diagnostics.

Parameters:

  • mu (float) – Location parameter.

  • sigma (float) – Positive scale parameter.

Returns:

Four ordered boundary points.

Return type:

numpy.ndarray
