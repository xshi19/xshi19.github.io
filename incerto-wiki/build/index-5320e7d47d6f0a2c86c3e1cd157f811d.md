# Notation

This is the canonical symbol table for Incerto Wiki. Concept pages, reading
guides, proofs, and executable examples should reuse these meanings rather than
redefining symbols locally. When a page needs a symbol that is missing here, add
it here first or state clearly that the page is using temporary local notation.

## Conventions

- Random variables are uppercase, such as $X$ and $Y$; realized values are
  lowercase, such as $x$ and $y$.
- Distribution functions are written $F$, survival functions $\bar F$, and
  densities or mass functions $f$ when they exist.
- Tail parameters are positive unless a page explicitly states a broader domain.
- Asymptotic statements specify the limit, usually $x \to \infty$ or
  $n \to \infty$.

## General Probability

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $X, Y$ | Random variables | Use uppercase for random quantities. |
| $x, y$ | Realizations or deterministic arguments | Use lowercase for values. |
| $F(x)$ | Distribution function $\mathbb P(X \le x)$ | The underlying random variable should be clear from context. |
| $\bar F(x)$ | Survival function $\mathbb P(X > x)$ | Primary object for tail comparisons. |
| $f(x)$ | Density or mass function | Only when it exists or is explicitly assumed. |
| $\mathbb E[X]$ | Expectation of $X$ | State existence assumptions for heavy-tailed variables. |
| $\operatorname{Var}(X)$ | Variance of $X$ | May be infinite for fat-tailed distributions. |
| $X_1,\dots,X_n$ | Sample of size $n$ | Independence and identical distribution must be stated when needed. |
| $S_n$ | Partial sum $\sum_{i=1}^n X_i$ | Used for laws of large numbers and max-to-sum comparisons. |
| $M_n$ | Sample maximum $\max_{1 \le i \le n} X_i$ | Used in extreme-value arguments. |

## Tail Behavior

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $\alpha$ | Tail exponent or Pareto shape parameter | Smaller $\alpha$ means a heavier Pareto tail. |
| $x_m$ | Pareto lower cutoff or scale | Assume $x \ge x_m > 0$ for the basic Pareto distribution. |
| $L(x)$ | Slowly varying function | $L(tx)/L(x) \to 1$ for fixed $t>0$ as $x\to\infty$. |
| $\bar F \in RV_{-\alpha}$ | Regularly varying survival tail with index $-\alpha$ | Equivalent to $\bar F(tx)/\bar F(x) \to t^{-\alpha}$ under the stated limit. |
| $\xi$ | Extreme-value index | Commonly $\xi = 1/\alpha$ for Pareto-type heavy tails. |
| $u$ | High threshold | Used in peaks-over-threshold and mean-excess examples. |
| $e(u)$ | Mean excess function $\mathbb E[X-u \mid X>u]$ | Requires the conditional mean to exist. |

## Estimation and Empirical Work

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $X_{1:n} \le \cdots \le X_{n:n}$ | Order statistics of a sample | Ascending order convention. |
| $k$ | Number of upper order statistics used for tail estimation | Typically $1 \le k < n$ and chosen by sensitivity analysis. |
| $\widehat\alpha$ | Estimated tail exponent | Specify the estimator, threshold, and sample transformation. |
| $\widehat\xi$ | Estimated extreme-value index | Often reported by Hill-type estimators. |
