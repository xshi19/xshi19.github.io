# Incerto Wiki Content

Welcome to the content surface for Incerto Wiki. For now, the MyST/Jupyter Book
site intentionally exposes only pages under `content/`: notation, glossary,
concept stubs, and reading-guide stubs. Project docs such as design notes,
agent guidance, and implementation plans remain in the repository but outside
the published MyST table of contents until the content model stabilizes.

## Starting Points

- [Notation](notation/index.md): shared mathematical symbols used across the
  wiki.
- [Glossary](glossary/index.md): short prose definitions for recurring terms.
- [Lean Blueprint](formalization/lean-blueprint.md): modest formalization
  scope for the simplest useful statements.
- [Releases](releases/releases.md): stable chapter-cycle release records and
  verification gates.
- [Chinese Entry Point](zh-cn/chinese-entry.md): bilingual-support scaffold.
- [Concept Dependency DAG](concepts/dependency-dag.md): current map of concept
  dependencies and missing nodes.
- [Pareto Distribution](concepts/distributions/pareto.md): first distribution
  concept stub for the Taleb-first cycle.
- [SCoFT Reading Guide](reading-guides/taleb-scoft/intro.md): entry point for
  the Taleb reading-guide track.
