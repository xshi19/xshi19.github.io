# Notation

This is the shared mathematical symbol table for Incerto Wiki. Concept pages,
reading guides, proofs, and executable examples should reuse these meanings for
symbols that appear across multiple pages. Page-specific symbols should be
declared on the page that uses them, then promoted here only when they become
common.

## Conventions

- Random variables and random samples are uppercase, such as $X$, $Y$, and
  $X_1,\dots,X_n$; realized values, observed samples, and deterministic data
  are lowercase, such as $x$, $y$, and $x_1,\dots,x_n$.
- Distribution functions are written $F$, survival functions $\bar F$, and
  densities or mass functions $f$ when they exist.
- Tail parameters are positive unless a page explicitly states a broader domain.
- Asymptotic statements specify the limit, usually $x \to \infty$ or
  $n \to \infty$.

## General Probability

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $X, Y$ | Random variables | Use uppercase for random quantities. |
| $x, y$ | Realizations or deterministic arguments | Use lowercase for values. |
| $F(x)$ | Distribution function $\mathbb P(X \le x)$ | The underlying random variable should be clear from context. |
| $\bar F(x)$ | Survival function $\mathbb P(X > x)$ | Primary object for tail comparisons. |
| $f(x)$ | Density or mass function | Only when it exists or is explicitly assumed. |
| $\mathbb E[X]$ | Expectation of $X$ | State existence assumptions for heavy-tailed variables. |
| $\operatorname{Var}(X)$ | Variance of $X$ | May be infinite for fat-tailed distributions. |
| $p$ | Moment order | Used in statements about $\mathbb E[X^p]$ and truncated moments. |
| $\mathbf 1_A$ | Indicator of event $A$ | Equals $1$ when $A$ occurs and $0$ otherwise. |
| $X_1,\dots,X_n$ | Random sample of size $n$ | Use uppercase for random quantities; state independence and identical distribution when needed. |
| $x_1,\dots,x_n$ | Realized sample or observed data of size $n$ | Use lowercase for data values plugged into estimators or plots. |
| $S_n$ | Random partial sum $\sum_{i=1}^n X_i$ | Used for laws of large numbers and random max-to-sum comparisons. |
| $M_n$ | Random sample maximum $\max_{1 \le i \le n} X_i$ | Used in extreme-value arguments. |
| $R_n$ | Random max-to-sum ratio $M_n/S_n$ | Defined for nonnegative random samples with $S_n>0$. |
| $s_n,m_n,r_n$ | Realized sum, maximum, and max-to-sum ratio | Use lowercase for observed data diagnostics. |

## Tail Behavior

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $\alpha$ | Tail exponent or Pareto shape parameter | Smaller $\alpha$ means a heavier Pareto tail. |
| $x_m$ | Pareto lower cutoff or scale | Assume $x \ge x_m > 0$ for the basic Pareto distribution. |
| $L(x)$ | Slowly varying function | $L(tx)/L(x) \to 1$ for fixed $t>0$ as $x\to\infty$. |
| $\bar F \in RV_{-\alpha}$ | Regularly varying survival tail with index $-\alpha$ | Equivalent to $\bar F(tx)/\bar F(x) \to t^{-\alpha}$ under the stated limit. |
| $\xi$ | Extreme-value index | Shape parameter in GEV/GPD limits; $\xi=1/\alpha$ for Pareto-type heavy tails. |
| $\beta$ | Generalized Pareto scale in EVT pages | Use local declarations when $\beta$ has another page-specific meaning. |
| $u$ | High threshold | Used in peaks-over-threshold and mean-excess examples. |
| $x_F$ | Right endpoint $\sup\{x:F(x)<1\}$ | May be finite or infinite. Used in threshold-excess limit statements. |

## Estimation and Empirical Work

| Symbol | Meaning | Notes |
| --- | --- | --- |
| $X_{1:n} \le \cdots \le X_{n:n}$ | Random order statistics of $X_1,\dots,X_n$ | Ascending order convention. |
| $x_{1:n} \le \cdots \le x_{n:n}$ | Realized order statistics of observed data $x_1,\dots,x_n$ | Use in formulas for numerical estimators. |
| $k$ | Number of upper order statistics used for tail estimation | Typically $1 \le k < n$ and chosen by sensitivity analysis. |
| $\widehat\alpha$ | Estimated tail exponent | Specify the estimator, threshold, and sample transformation. |
| $\widehat\xi$ | Estimated extreme-value index | Often reported by Hill-type estimators. |
