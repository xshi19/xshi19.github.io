Pre-Asymptotic LLN Behavior

Setup¶

This synthetic example plots running means

Xˉn=Snn\bar X_n=\frac{S_n}{n}Xˉn​=nSn​​
(1)

for iid Pareto Type I samples with xm=1x_m=1xm​=1. The target contrast is:

  • if α≤1\alpha\le1α≤1, LLN Failure Under Infinite Mean says Xˉn→∞\bar X_n\to\inftyXˉn​→∞ almost surely;

  • if α>1\alpha>1α>1, the finite-mean law of large numbers says Xˉn→α/(α−1)\bar X_n\to\alpha/(\alpha-1)Xˉn​→α/(α−1), but convergence can still be slow when α\alphaα is close to 1.

The symbols Xˉn\bar X_nXˉn​, SnS_nSn​, α\alphaα, and xmx_mxm​ follow the shared notation table.

What the simulation isolates¶

The simulation uses exact iid Pareto draws. It does not include dependence, threshold fitting, censoring, mixtures, or measurement error. That narrow setup is deliberate: it isolates why the theorem can be practically easy to underestimate even before empirical complications enter.

The inverse-transform representation is

X=(1−U)−1/α,U∼Uniform⁡(0,1).X=(1-U)^{-1/\alpha},\qquad U\sim \operatorname{Uniform}(0,1).X=(1−U)−1/α,U∼Uniform(0,1).
(2)

The distribution helper in incerto.distributions implements the same Pareto Type I law.

Running-mean paths¶

The left panel shows single running-mean paths at log-spaced checkpoints. The right panel summarizes repeated final sample means at several sample sizes.

Source
import numpy as np
import matplotlib.pyplot as plt

from incerto.distributions import pareto_type1
from incerto.estimators import max_to_sum_ratio, running_mean
from incerto.figures import COLORS, FIGURE_SIZES, set_theme, style_axes

set_theme()

path_n = 300_000
checkpoints = np.unique(np.geomspace(10, path_n, 90).astype(int))
path_specs = [
    (0.8, 20260617, COLORS["brick"]),
    (1.0, 20260618, COLORS["umber"]),
    (1.3, 20260619, COLORS["green"]),
]

n_values = np.array([300, 1_000, 3_000, 10_000, 30_000])


def final_mean_quantiles(alpha, n, reps=300, batch=50, seed=20260617):
    rng = np.random.default_rng(seed)
    means = np.empty(reps)
    for start in range(0, reps, batch):
        stop = min(start + batch, reps)
        sample = pareto_type1.rvs(
            alpha,
            size=(stop - start, n),
            random_state=rng,
        )
        means[start:stop] = sample.mean(axis=1)
    return np.quantile(means, [0.10, 0.50, 0.90])


fig, axes = plt.subplots(1, 2, figsize=FIGURE_SIZES["two_panel"])

for alpha, seed, color in path_specs:
    rng = np.random.default_rng(seed)
    sample = pareto_type1.rvs(alpha, size=path_n, random_state=rng)
    means = running_mean(sample)

    axes[0].loglog(
        checkpoints,
        means[checkpoints - 1],
        color=color,
        label=fr"$\alpha={alpha}$",
    )

    if alpha > 1:
        axes[0].axhline(alpha / (alpha - 1), color=color, ls="--", alpha=0.8)

    print(f"Pareto alpha={alpha}:")
    print(f"  final running mean after {path_n:,} draws: {float(means[-1]):.3f}")
    print(f"  largest observation's share of total: {float(max_to_sum_ratio(sample)):.3f}")
    if alpha > 1:
        print(f"  finite theoretical mean: {alpha / (alpha - 1):.3f}")
    else:
        print("  finite theoretical mean: none")

axes[0].set_xlabel("sample size n")
axes[0].set_ylabel("running mean")
axes[0].set_title("Single running-mean paths")
axes[0].legend()

for alpha, color in [(0.8, COLORS["brick"]), (1.3, COLORS["green"])]:
    qs = np.array(
        [
            final_mean_quantiles(alpha, n, seed=20260617 + int(100 * alpha) + n)
            for n in n_values
        ]
    )
    axes[1].fill_between(n_values, qs[:, 0], qs[:, 2], color=color, alpha=0.18)
    axes[1].plot(n_values, qs[:, 1], color=color, marker="o", label=fr"$\alpha={alpha}$ median")

axes[1].axhline(1.3 / (1.3 - 1), color=COLORS["green"], ls="--", alpha=0.8)
axes[1].set_xscale("log")
axes[1].set_yscale("log")
axes[1].set_xlabel("sample size n")
axes[1].set_ylabel("sample-mean quantiles")
axes[1].set_title("Repeated-simulation bands")
axes[1].legend()

style_axes(axes, grid_axis="both")
plt.show()

What to notice. For α≤1\alpha\le1α≤1, no finite theoretical mean exists. For α=1.3\alpha=1.3α=1.3, the finite mean exists, but large observations still create visible pre-asymptotic jumps and wide repeated-simulation bands.

Interpretation and caveats¶

  • One simulated path is not a proof and not an estimator of α\alphaα.

  • The plot uses log axes. This makes early and late behavior comparable, but it also visually compresses large jumps.

  • A path with α>1\alpha>1α>1 can look worse than a path with α≤1\alpha\le1α≤1 over a finite window if it happens to receive an unusually large early draw.

  • Real data adds threshold choice, dependence, measurement limits, and model uncertainty. The example isolates only the iid Pareto mechanism.
