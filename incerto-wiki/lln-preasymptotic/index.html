Pre-Asymptotic LLN Behavior

Statement¶

This example plots the running mean

Xˉn=Snn\bar X_n=\frac{S_n}{n}Xˉn​=nSn​​
(1)

for iid Pareto Type I samples with xm=1x_m=1xm​=1. The plot uses log-spaced checkpoints up to 106 draws so that early instability and late record shocks can be seen on the same scale.

The target contrast is:

  • if α≤1\alpha\le1α≤1, LLN Failure Under Infinite Mean says Xˉn→∞\bar X_n\to\inftyXˉn​→∞ almost surely;

  • if α>1\alpha>1α>1, the finite-mean law of large numbers says Xˉn→α/(α−1)\bar X_n\to\alpha/(\alpha-1)Xˉn​→α/(α−1), but convergence can still be slow when α\alphaα is close to 1.

Intuition¶

The hard part is not that a heavy-tailed running mean is noisy. The hard part is that the noise does not live on a stable scale. One large observation can move the average after thousands or millions of previous observations, and the sample path can look calmer right before the next record arrives.

Compare the infinite-mean region near α=1\alpha=1α=1 with the finite-mean region just above it. The plot is not a proof; it is a finite-sample view of why the theorem is practically easy to underestimate.

Proof¶

The simulation uses the inverse-transform representation of a Pareto Type I sample:

X=(1−U)−1/α,U∼Uniform⁡(0,1).X=(1-U)^{-1/\alpha},\qquad U\sim \operatorname{Uniform}(0,1).X=(1−U)−1/α,U∼Uniform(0,1).
(2)

For each selected α\alphaα, it generates one iid path, computes Sn/nS_n/nSn​/n at log-spaced checkpoints, and plots the result on log-log axes. The infinite mean claim itself is proved in LLN Failure Under Infinite Mean; this page is an empirical illustration of the finite-sample path.

Python¶

The code uses the reusable running_mean and max_to_sum_ratio helpers from incerto.estimators.

import numpy as np
import matplotlib.pyplot as plt

from incerto.distributions import pareto_type1
from incerto.estimators import max_to_sum_ratio, running_mean
from incerto.figures import COLORS, FIGURE_SIZES, set_theme, style_axes

set_theme()

n = 1_000_000
checkpoints = np.unique(np.geomspace(10, n, 90).astype(int))

fig, ax = plt.subplots(figsize=FIGURE_SIZES["single"])

for alpha, seed, color in [
    (0.8, 20260523, COLORS["brick"]),
    (1.3, 20260525, COLORS["green"]),
]:
    rng = np.random.default_rng(seed)
    sample = pareto_type1.rvs(alpha, size=n, random_state=rng)
    means = running_mean(sample)

    ax.loglog(
        checkpoints,
        means[checkpoints - 1],
        color=color,
        label=f"alpha={alpha}",
    )

    final_mean = float(means[-1])
    max_share = float(max_to_sum_ratio(sample))
    print(f"Pareto alpha={alpha}:")
    print(f"  final running mean after {n:,} draws: {final_mean:.3f}")
    print(f"  largest observation's share of total: {max_share:.3f}")

    if alpha > 1:
        print(f"  finite theoretical mean: {alpha / (alpha - 1):.3f}")
        ax.axhline(
            alpha / (alpha - 1),
            color=color,
            ls="--",
            alpha=0.8,
        )
    else:
        print("  finite theoretical mean: none")

ax.set_xlabel("sample size n")
ax.set_ylabel("running mean")
ax.set_title("Pre-asymptotic running means")
ax.legend()
style_axes(ax, grid_axis="both")
plt.show()
Pareto alpha=0.8:
  final running mean after 1,000,000 draws: 91.390
  largest observation's share of total: 0.054
  finite theoretical mean: none
Pareto alpha=1.3:
  final running mean after 1,000,000 draws: 4.118
  largest observation's share of total: 0.006
  finite theoretical mean: 4.333

For α=0.8\alpha=0.8α=0.8, no finite theoretical mean exists. For α=1.3\alpha=1.3α=1.3, the finite mean exists, but large observations still create visible pre-asymptotic jumps.

Caveats¶

  • One simulated path is not a proof and not an estimator of α\alphaα.

  • The plot uses log axes. This makes early and late behavior comparable, but it also visually compresses large jumps.

  • A path with α>1\alpha>1α>1 can look worse than a path with α≤1\alpha\le1α≤1 over a finite window if it happens to receive an unusually large early draw.

  • Real data adds threshold choice, dependence, measurement limits, and model uncertainty. The example isolates only the iid Pareto mechanism.
