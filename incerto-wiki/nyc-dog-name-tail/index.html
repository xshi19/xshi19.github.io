Are NYC Dog Names Fat-Tailed?

Setup¶

John D. Cook’s blog post “Dogs and fat tails” asks a delightful question: how wild is the distribution of dog names? Bella and Luna have plenty of company, while thousands of names appear only once Cook, 2026. A lognormal describes the overall pattern reasonably well. Here we draw the rank-frequency picture too, then poke at the far right tail to see whether a Pareto exponent holds still.

The source is the NYC Department of Health and Mental Hygiene’s NYC Dog Licensing Dataset New York City Department of Health and Mental Hygiene, 2026. Each source row is an active license period, not necessarily a unique dog. A renewal within the same year can add another row for the same animal. We therefore call the aggregated values license-period frequencies, not dog counts.

We use the full public dataset, not a little row sample. The Socrata API does the compacting for us: trim and uppercase the names, drop missing-name placeholders, and return one count per name. The result is only about 35,000 rows instead of nearly 800,000 license records, so the complete aggregate is small enough to travel with the page.

What is being estimated?¶

Let xix_ixi​ be the number of included license-period records attached to the iiith observed normalized name. The sample for the tail diagnostics is

x1,…,xn,x_1,\ldots,x_n,x1​,…,xn​,
(1)

where nnn is the number of distinct names in the snapshot. A large xix_ixi​ means that a name is popular. Names that do not occur in the licensing data are absent, so this is a zero-truncated frequency spectrum rather than a sample of all possible names.

A whole-sample lognormal fit and a tail estimate answer different questions. The first summarizes all positive frequencies. The second requires a high threshold and asks whether the observations above it behave approximately like a regularly varying right tail. We use the Hill estimator and a generalized Pareto shape fit across many candidate thresholds, following Tail Threshold Selection. No body/shoulder boundary supplies that threshold automatically.

First, the dog-name popularity curve¶

Sort names from most to least frequent, give them ranks 1,2,…,n1,2,\ldots,n1,2,…,n, and plot rank against frequency. A power law would look roughly straight on log-log axes. The dashed line is an ordinary least-squares fit in log space; it is a visual summary, not a claim that dog naming follows an exact law.

Global fit and threshold sensitivity¶

The survival plot compares the data with the blog’s global lognormal baseline. Below it, two roomier panels use only upper frequencies and expose the threshold choice. The generalized Pareto fit uses the GPD shape parameter ξ\xiξ; the Hill panel reports the Pareto tail exponent α^=1/ξ^\widehat\alpha=1/\widehat\xiα=1/ξ​. These symbols follow the shared notation table.

import warnings

import matplotlib.pyplot as plt
import numpy as np
from scipy.stats import genpareto, linregress, lognorm

from incerto.datasets import load_nyc_dog_name_frequencies
from incerto.estimators import hill_stability
from incerto.figures import COLORS, FIGURE_SIZES, set_theme, style_axes

set_theme()

data = load_nyc_dog_name_frequencies()
frequencies = data.frequency.astype(float)
ordered = np.sort(frequencies)
n = ordered.size
empirical_survival = 1 - np.arange(1, n + 1) / (n + 1)

# Rank-frequency view, from the most common name down to the one-offs.
ranked_frequency = ordered[::-1]
name_rank = np.arange(1, n + 1)
slope, intercept, r_value, _, _ = linregress(
    np.log(name_rank), np.log(ranked_frequency)
)

fig, ax = plt.subplots(figsize=FIGURE_SIZES["single"])
ax.scatter(
    name_rank,
    ranked_frequency,
    s=10,
    alpha=0.35,
    color=COLORS["accent"],
)
rank_grid = np.geomspace(name_rank.min(), name_rank.max(), 200)
ax.plot(
    rank_grid,
    np.exp(intercept) * rank_grid**slope,
    color=COLORS["umber"],
    linestyle="--",
    label=f"log-log slope {slope:.2f}",
)
ax.set_xscale("log")
ax.set_yscale("log")
ax.set_xlabel("name popularity rank")
ax.set_ylabel("license-period frequency")
ax.set_title("Dog-name rank-frequency relation")
ax.legend()
style_axes(ax, grid_axis="both")
plt.show()

# Descriptive whole-sample baseline: a two-parameter lognormal with location 0.
lognormal_shape, _, lognormal_scale = lognorm.fit(frequencies, floc=0.0)
fitted_survival = lognorm.sf(
    ordered,
    lognormal_shape,
    loc=0.0,
    scale=lognormal_scale,
)

# Hill sensitivity over upper order statistics.
report_ks = np.array([50, 100, 200, 500, 1_000, 2_000, 5_000])
ks = np.unique(
    np.concatenate(
        [np.geomspace(25, min(8_000, n // 3), 100).astype(int), report_ks]
    )
)
hill = hill_stability(frequencies, ks)
hill_k = hill["k"].astype(int)
hill_threshold = ordered[-(hill_k + 1)]
hill_order = np.argsort(hill_threshold)

# GPD shape sensitivity over fixed integer thresholds.
gpd_thresholds = np.unique(np.geomspace(20, 500, 28).round().astype(int))
gpd_xi = []
gpd_exceedances = []
for threshold in gpd_thresholds:
    excesses = frequencies[frequencies > threshold] - threshold
    with warnings.catch_warnings():
        warnings.simplefilter("ignore")
        xi_hat, loc_hat, _ = genpareto.fit(excesses, floc=0.0)
    if abs(loc_hat) > 1e-10:
        raise RuntimeError("GPD fit did not respect the fixed zero location")
    gpd_xi.append(xi_hat)
    gpd_exceedances.append(excesses.size)

gpd_xi = np.array(gpd_xi)
gpd_exceedances = np.array(gpd_exceedances)

fig, ax = plt.subplots(figsize=FIGURE_SIZES["single"])
ax.loglog(
    ordered,
    empirical_survival,
    color=COLORS["accent"],
    label="empirical",
)
ax.loglog(
    ordered,
    fitted_survival,
    color=COLORS["umber"],
    linestyle="--",
    label="whole-sample lognormal",
)
ax.set_xlabel("license-period frequency")
ax.set_ylabel("survival across names")
ax.set_title("Global frequency fit")
ax.legend()
style_axes(ax, grid_axis="both")
plt.show()

fig, axes = plt.subplots(1, 2, figsize=FIGURE_SIZES["two_panel"])

axes[0].semilogx(
    hill_threshold[hill_order],
    hill["alpha"][hill_order],
    color=COLORS["green"],
)
axes[0].set_xlabel("empirical threshold")
axes[0].set_ylabel(r"Hill $\widehat\alpha$")
axes[0].set_title("Pareto-exponent sensitivity")

xi_line = axes[1].semilogx(
    gpd_thresholds,
    gpd_xi,
    marker="o",
    color=COLORS["teal"],
    label=r"GPD $\widehat\xi$",
)
count_axis = axes[1].twinx()
count_line = count_axis.semilogx(
    gpd_thresholds,
    gpd_exceedances,
    color=COLORS["muted"],
    linestyle=":",
    label="exceedances",
)
axes[1].set_xlabel("fixed threshold")
axes[1].set_ylabel(r"GPD $\widehat\xi$")
count_axis.set_ylabel("exceedances")
axes[1].set_title("GPD threshold sensitivity")
axes[1].legend(
    xi_line + count_line,
    [line.get_label() for line in xi_line + count_line],
)

style_axes([*axes, count_axis], grid_axis="both")
plt.show()

print("NYC dog-name frequencies")
print(f"  Normalized names: {data.name.size:,}")
print(f"  Included license-period records: {data.frequency.sum():,}")
print(f"  Largest name frequency: {data.frequency.max():,}")
print(f"  Rank-frequency log-log slope: {slope:.3f} (R^2={r_value**2:.3f})")
print(

)
print("\nSelected tail-sensitivity points")
for k in report_ks:

        i = index[0]

            f"  k={k:5,d}; threshold={hill_threshold[i]:6.0f}; "

The survival view adds a finding beyond the global distribution label: the empirical far-right curve lies above the whole-sample lognormal fit. The tail panels then show that this extra upper-tail mass does not settle into a broad, flat Hill region. The GPD shape estimate also falls as the threshold rises while the number of exceedances shrinks. The data therefore do not support reporting one threshold-insensitive Pareto exponent.

This does not establish a lognormal data-generating mechanism. It says that, within the observed pooled snapshot, the upper frequencies do not give stable evidence for one Pareto-type tail. A lognormal or another non-Pareto model can mimic a power law over a finite range, and the current sample does not settle the asymptotic class.

A name lookup¶

The same aggregate can answer case-insensitive name-frequency questions. The result remains a count of license-period rows unless the underlying records can be shown to represent different dogs.

lookup_name = "Safari"
lookup_frequency = data.frequency_for(lookup_name)
print(
    f"{lookup_name}: {lookup_frequency:,} included license-period "
    f"record{'s' if lookup_frequency != 1 else ''}"
)
Safari: 3 included license-period records

Caveats¶

  • The source counts license periods. Renewals can cause multiple rows for one dog, and the public columns do not contain a stable dog identifier.

  • The dataset pools extract years. It mixes changing name preferences, population turnover, and repeated licensing periods.

  • Uppercasing and trimming do not merge spelling, punctuation, or transcription variants.

  • Frequencies are discrete, tied, and dependent because they sum to the total number of included records. The iid continuous-tail assumptions behind Hill and GPD asymptotics are therefore approximations here.

  • Only observed names enter the sample. Unused possible names have zero frequency and are not represented.

  • Threshold stability is an empirical diagnostic, not a proof of a tail class. A larger or differently deduplicated sample could give a different pattern.
