Pareto Distribution

Statement¶

Let XXX be a positive random variable with lower cutoff xm>0x_m>0xm​>0 and tail exponent α>0\alpha>0α>0. The Pareto Type I distribution is defined by the survival function

Fˉ(x)=P(X>x)={1,0≤x<xm,(xmx)α,x≥xm.\bar F(x) = \mathbb P(X>x) = \begin{cases} 1, & 0 \le x < x_m,\\ \left(\frac{x_m}{x}\right)^\alpha, & x \ge x_m. \end{cases}Fˉ(x)=P(X>x)={1,(xxm​​)α,​0≤x<xm​,x≥xm​.​
(1)

F(x)=1−(xmx)α,f(x)=αxmαx−(α+1).F(x)=1-\left(\frac{x_m}{x}\right)^\alpha,\qquad f(x)=\alpha x_m^\alpha x^{-(\alpha+1)}.F(x)=1−(xxm​​)α,f(x)=αxmα​x−(α+1).
(2)

For probability level 0<q<10<q<10<q<1, the quantile function is

Q(q)=xm(1−q)−1/α.Q(q)=x_m(1-q)^{-1/\alpha}.Q(q)=xm​(1−q)−1/α.
(3)

The raw moment of order p>0p>0p>0 is finite exactly when p<αp<\alphap<α:

E[Xp]=αxmpα−p,p<α.\mathbb E[X^p]=\frac{\alpha x_m^p}{\alpha-p},\qquad p<\alpha.E[Xp]=α−pαxmp​​,p<α.
(4)

For p≥αp\ge\alphap≥α, the moment is infinite. At p=αp=\alphap=α the divergence is logarithmic; for p>αp>\alphap>α it is a power divergence. In particular, the mean exists only for α>1\alpha>1α>1, and the variance exists only for α>2\alpha>2α>2.

Intuition¶

The Pareto tail has no characteristic scale. Multiplying the threshold by a fixed factor changes the exceedance probability by a fixed power:

Fˉ(tx)Fˉ(x)=t−α,t>0.\frac{\bar F(tx)}{\bar F(x)}=t^{-\alpha},\qquad t>0.Fˉ(x)Fˉ(tx)​=t−α,t>0.
(5)

This is why the exponent α\alphaα is the central knob. Smaller α\alphaα means that threshold doublings are punished less severely, so rare observations remain large enough to dominate sums, moments, and empirical estimates.

(6)

E[Xp]=∫xm∞xpαxmαx−(α+1) dx=αxmα∫xm∞xp−α−1 dx.\mathbb E[X^p] =\int_{x_m}^{\infty}x^p\alpha x_m^\alpha x^{-(\alpha+1)}\,dx =\alpha x_m^\alpha\int_{x_m}^{\infty}x^{p-\alpha-1}\,dx.E[Xp]=∫xm​∞​xpαxmα​x−(α+1)dx=αxmα​∫xm​∞​xp−α−1dx.

Python¶

The package implementation uses the same tail exponent α\alphaα and the SciPy-style scale keyword for the lower cutoff xmx_mxm​.

import numpy as np
import matplotlib.pyplot as plt

from incerto.distributions import pareto_type1
from incerto.figures import FIGURE_SIZES, set_theme, style_axes

np.set_printoptions(precision=4, suppress=True)
set_theme()

alpha = 1.16
x_m = 1.0

x = np.array([1, 2, 4, 8, 16], dtype=float)
survival = pareto_type1.sf(x, alpha, scale=x_m)
ratio = pareto_type1.sf(2 * x, alpha, scale=x_m) / survival
mean, variance = pareto_type1.stats(alpha, scale=x_m, moments="mv")

x_grid = np.geomspace(x_m, 100, 200)
fig, ax = plt.subplots(figsize=FIGURE_SIZES["single"])
for exponent in (0.8, 1.5, 3.0):
    ax.loglog(
        x_grid,
        pareto_type1.sf(x_grid, exponent, scale=x_m),
        label=f"alpha={exponent}",
    )

ax.set_xlabel("threshold x")
ax.set_ylabel("survival P(X > x)")
ax.set_title("Pareto survival tails")
ax.legend()
style_axes(ax, grid_axis="both")
plt.show()

print(f"Survival values at x={x.tolist()}: {survival}")
print(f"Survival ratio P(X>2x)/P(X>x): {ratio}")
print(f"Mean and variance: {(float(mean), float(variance))}")

The package also includes incerto.distributions.double_pareto, which uses the same tail exponent on both sides of the origin.

Caveats¶

  • Taleb often writes the tail exponent as aaa; the wiki uses α\alphaα.

  • Empirical data rarely follows an exact Pareto law from its minimum value. A tail model needs a threshold choice, diagnostic plots, and sensitivity checks.

  • A finite theoretical mean can still be practically hard to estimate when α\alphaα is close to 1. The issue is pre-asymptotic behavior, not merely the formal existence of E[X]\mathbb E[X]E[X].

  • The exact failure mode depends on the moment order. At p=αp=\alphap=α, the cutoff moment grows like log⁡x\log xlogx; for p>αp>\alphap>α, it grows like xp−αx^{p-\alpha}xp−α.

  • Do not estimate high moments of heavy-tailed samples without checking whether those moments are implied by the fitted tail exponent.
