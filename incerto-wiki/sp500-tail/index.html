S&P 500 Tail Diagnostics

Setup¶

This empirical example applies one-sided tail diagnostics to positive daily S&P 500 close-to-close log losses,

Lt=−log⁡(Pt/Pt−1)on days with Pt<Pt−1,L_t=-\log(P_t/P_{t-1})\quad\text{on days with }P_t<P_{t-1},Lt​=−log(Pt​/Pt−1​)on days with Pt​<Pt−1​,
(1)

where PtP_tPt​ is the closing index level. Zero-return or up-return days are not part of the Hill sample, because the Hill estimator requires strictly positive right-tail observations. We use the S&P 500 series as made available through FRED S&P Dow Jones Indices LLC, 2026.

The raw index series is not committed to the repository. The executable cell reads an untracked local cache at data/cache/sp500_daily.csv when that cache is present; otherwise it skips with a data-availability note. The refresh script can populate the cache from FRED or from a locally obtained CSV. This keeps the site source reproducible without redistributing S&P index data or making public builds depend on a live FRED request.

Empirical tail question¶

Financial returns are two-sided, so a right-tail method has to be applied to a one-sided transformation. Here the transformed variable is daily loss. A large positive value of LtL_tLt​ means the index fell sharply from one close to the next.

The goal is modest: inspect whether large daily losses behave more like a thin-tail sample or a heavy right-tail sample over the observed window. The plot and estimates are diagnostics, not a trading model or a forecast.

Diagnostics¶

There is no theorem proving that equity-index losses follow a Pareto law. The computation has three reproducible steps:

  1. Clean daily closes into a date/close cache.

  2. Transform closes into positive log losses.

  3. Apply Tail Threshold Selection, the Hill estimator, and Mean Excess Function to the loss sample.

Any claim made from this page is empirical and conditional on the sample window, the one-day horizon, and the threshold choices.

import numpy as np
import matplotlib.pyplot as plt
from IPython.display import Markdown, display

from incerto.datasets import DatasetNotAvailable, load_sp500_prices
from incerto.estimators import hill_alpha_estimator, hill_stability, mean_excess
from incerto.figures import COLORS, FIGURE_SIZES, set_theme, style_axes

set_theme()

try:
    prices = load_sp500_prices(fetch=False)
except DatasetNotAvailable:
    display(
        Markdown(
            "**Data unavailable in this build.** The S&P 500 cache is "
            "deliberately untracked because FRED notes S&P Dow Jones "
            "redistribution restrictions. To reproduce the diagnostics, run "
            "`python scripts/fetch_data.py sp500` with network access and "
            "rebuild the page locally."
        )
    )
else:
    loss_dates, losses = prices.negative_log_returns()
    print(
        f"{prices.name}: {prices.date[0]} to {prices.date[-1]}, "
        f"{prices.close.size:,} closes, {losses.size:,} negative-return days"
    )

    order = np.sort(losses)
    survival = 1 - np.arange(1, order.size + 1) / (order.size + 1)

    ks = np.unique(
        np.geomspace(10, min(500, max(11, losses.size // 3)), 80).astype(int)
    )
    stability = hill_stability(losses, ks)

    thresholds = np.quantile(losses, np.linspace(0.80, 0.99, 35))
    me = mean_excess(losses, thresholds, min_exceedances=20)

    fig, axes = plt.subplots(3, 1, figsize=(6.4, 10.8), constrained_layout=True)

    axes[0].loglog(order, survival, color=COLORS["accent"])
    axes[0].set_xlabel("daily log loss")
    axes[0].set_ylabel("empirical survival")
    axes[0].set_title("Loss survival")

    axes[1].semilogx(stability["k"], stability["alpha"], color=COLORS["umber"])
    axes[1].set_xlabel("upper order statistics k")
    axes[1].set_ylabel(r"Hill $\widehat\alpha$")
    axes[1].set_title("Hill stability")

    axes[2].plot(me["threshold"], me["mean_excess"], color=COLORS["green"])
    axes[2].set_xlabel("threshold u")
    axes[2].set_ylabel("mean excess")
    axes[2].set_title("Mean excess")

    style_axes(axes, grid_axis="both")
    plt.show()

    for k in [25, 50, 100, 200, 400]:
        if k < losses.size:
            print(f"Hill alpha for k={k:3d}: {hill_alpha_estimator(losses, k):.2f}")

    largest = np.argsort(losses)[-5:][::-1]
    print("Largest one-day log losses:")
    for i in largest:
        print(f"  {loss_dates[i]}: {losses[i]:.3f}")

The survival, Hill, and mean-excess panels give related but not identical views of the right tail. The Hill estimates should be read as a sensitivity range, not a single fitted truth. The largest observations usually identify crisis days, which is exactly why iid threshold models need caveats for dependence and volatility clustering.

Interpretation and caveats¶

  • The S&P 500 cache is local and untracked because the underlying index data has redistribution restrictions. Do not commit raw S&P index levels without checking the license.

  • Daily index losses are dependent and volatility-clustered. A plain iid tail fit ignores that structure.

  • The analysis uses price-index closes, not total returns with dividends.

  • Threshold choice dominates finite-sample tail estimates. Report kkk, threshold, sample window, and transformation.

  • A heavy-tail diagnostic is not a forecast of tomorrow’s loss.
