Python API

The installed distribution is xshi-math; these helpers are imported as xmath.incerto. Install the numerical and plotting extra with:

uv sync --locked --extra incerto

Run page examples in Python after installing from a repository checkout. Every fenced python block on the Incerto pages is executed by pytest; examples do not fetch data or save files. Each Output block is captured from its preceding example and checked against stdout, ignoring trailing whitespace only. Bundled dataset examples require an editable checkout (or a populated INCERTO_DATA_DIR). Longer examples expand under a Code dropdown.

Numeric output uses about four significant digits or three to four decimal places, with scientific notation for small probabilities. Counts remain integers; vectors print as short lists and dictionaries as key: value lines. Mathematical infinities and missing values print as inf and nan.

The base xmath helpers require only NumPy. The Incerto extra adds SciPy and Matplotlib; graph generation uses NetworkX and PyYAML from the development group. Dataset fetching uses standard-library urllib. The Python modules contain the full signatures and docstrings; there is no separate Sphinx build. Browse the module sources for implementations and use local help() for the installed version.

Use pareto_type1 and hill_alpha_estimator.

import numpy as np
from xmath.incerto.distributions import pareto_type1
from xmath.incerto.estimators import hill_alpha_estimator

rng = np.random.default_rng(20261017)
x = pareto_type1.rvs(2.5, size=1000, random_state=rng)
alpha_hat = hill_alpha_estimator(x, k=100)
print(f"Estimated alpha: {alpha_hat:.3f}")

Output

Estimated alpha: 2.405

The example is a simulation, not a guarantee about estimation accuracy. The Hill note states the model and threshold assumptions. Use help() on an imported function for argument validation, return types, and numerical limits.

The empirical examples link to committed demo scripts and static figures. Dataset loading does not fetch by default. The S&P method explains the deliberately absent financial cache. The separate Normix API remains maintained upstream; this educational package does not vendor Normix.

Distributions¶

Module: xmath.incerto.distributions.

Call an object below with its shape parameters to freeze a law; then use pdf(x), logpdf(x), cdf(x), sf(x), logsf(x), ppf(q), rvs(size=..., random_state=rng) or stats(moments="mv"). These methods belong to the linked distribution entry. scale is a positive scale multiplier, and loc shifts the support.

pareto_type1¶

pareto_type1(alpha, loc=0, scale=1)

Pareto Type I with positive exponent alpha; at loc=0, scale is the lower cutoff.

double_pareto¶

double_pareto(alpha, loc=0, scale=1)

Symmetric shifted double Pareto with positive exponent alpha; ordinary mean exists only above one.

hypsecant2¶

hypsecant2(loc=0, scale=1)

Density 0.5 / cosh(x)**2 at default location and scale (logistic scale one half).

simple_normal_mixture¶

simple_normal_mixture(a, loc=0, scale=1)

Equal centered normal mixture with component variances 1-a and 1+a, for 0 <= a < 1.

univariate_variance_gamma¶

univariate_variance_gamma(alpha, beta, lam, loc=0, scale=1)

Variance–gamma law requiring alpha > abs(beta) and lam > 0; this alpha is a decay parameter, not a Pareto exponent.

generalized_pareto¶

generalized_pareto(xi, beta=1.0)

Returns a frozen zero-location GPD with finite scalar shape ξ\xiξ and finite scale β>0\beta>0β>0. Methods include pdf, cdf, sf, logsf, ppf, rvs and support. Support is [0,∞)[0,\infty)[0,∞) for ξ≥0\xi\ge0ξ≥0 and [0,−β/ξ][0,-\beta/\xi][0,−β/ξ] for ξ<0\xi<0ξ<0. CDF/survival extend continuously at support boundaries. Endpoint densities can be infinite when ξ<−1\xi<-1ξ<−1. Invalid parameters raise ValueError.

from xmath.incerto.distributions import generalized_pareto

law = generalized_pareto(-0.4)
print("Survival: [" + ", ".join(f"{v:.4g}" for v in law.sf([-1, 0, 1, 2.5, 3])) + "]")

Output

Survival: [1, 1, 0.2789, 0, 0]

generalized_extreme_value¶

generalized_extreme_value(xi, mu=0.0, sigma=1.0)

Returns a frozen GEV with the page’s shape convention: positive ξ\xiξ is heavy-tailed, zero is Gumbel, negative has a finite right endpoint. The adapter uses scipy.stats.genextreme(c=-xi) and exposes the same methods as the GPD adapter. Require finite scalar parameters and σ>0\sigma>0σ>0. Outside support, density is zero and CDF/survival have their limiting values. For ξ<−1\xi<-1ξ<−1, the density diverges as the right endpoint is approached, although SciPy 1.18 returns zero at the endpoint itself. This single-point convention does not change probabilities. Invalid parameters raise ValueError.

from xmath.incerto.distributions import generalized_extreme_value

for xi in (-0.3, 0, 0.3):
    law = generalized_extreme_value(xi)
    print(f"xi={xi:.4g}: cdf(0)={law.cdf(0):.4g}, sf(4)={law.sf(4):.4g}")

Output

xi=-0.3: cdf(0)=0.3679, sf(4)=0
xi=0: cdf(0)=0.3679, sf(4)=0.01815
xi=0.3: cdf(0)=0.3679, sf(4)=0.06966

frechet¶

frechet(alpha, scale=1.0)

Returns a frozen zero-location Fréchet law with CDF exp⁡[−(y/scale)−α]\exp[-(y/\mathrm{scale})^{-\alpha}]exp[−(y/scale)−α] for y>0y>0y>0. Both parameters are finite positive scalars. Uses SciPy invweibull, including pdf, cdf, sf, logsf, ppf, rvs and support. At and below zero, density and CDF are zero, survival one. Use sf rather than subtracting cdf from one when the right tail is small. Invalid parameters raise ValueError. The adapter inherits SciPy’s numerical limits: for example, SciPy 1.18 returns nan for frechet(3).pdf(1e-100) because intermediate powers overflow, although the true density rounds to zero. The P1 figure grids avoid this range.

from xmath.incerto.distributions import frechet

law = frechet(1.5)
for y in (0, 1, 10):
    print(f"y={y:d}: pdf={law.pdf(y):.4g}, cdf={law.cdf(y):.4g}, sf={law.sf(y):.4g}")

Output

y=0: pdf=0, cdf=0, sf=1
y=1: pdf=0.5518, cdf=0.3679, sf=0.6321
y=10: pdf=0.004596, cdf=0.9689, sf=0.03113

max_to_sum_path¶

max_to_sum_path(x)

Returns the maximum divided by the sum for every prefix of a nonempty, finite, real, nonnegative one-dimensional list. Zero-total prefixes return nan. Log accumulation avoids overflow of the sum and avoids scaling early prefixes by a much larger future observation. Negative/nonfinite/complex values and wrong dimensions raise ValueError; ordinary rounding remains.

from xmath.incerto.estimators import max_to_sum_path

path = max_to_sum_path([0, 1, 1, 8])
print("Prefix ratios: [" + ", ".join(f"{v:.4g}" for v in path) + "]")

Output

Prefix ratios: [nan, 1, 0.5, 0.8]

gpd_threshold_fit¶

gpd_threshold_fit(x, threshold, *, min_exceedances=30)

Numerically fits a zero-location GPD to strict excesses above a finite threshold. Returns threshold, integer count, xi, beta, modified_scale (β^−ξ^u\widehat\beta-\widehat\xi uβ​−ξ​u), success and status. Finite real one-dimensional data are required; invalid input raises. Insufficient or constant excesses, overflow when forming excesses, and failed numerical fits retain counts but report nan parameters and an explanatory status. The optimizer stops at 2,000 iterations or 4,000 evaluations. Checks cover numerical convergence, finite parameters/log density, positive scale and every excess’s support. Success is no guarantee of a global MLE, a valid tail model or an appropriate threshold. No confidence interval is returned.

from xmath.incerto.estimators import gpd_threshold_fit

fit = gpd_threshold_fit([1, 2, 2, 4], 2, min_exceedances=2)
print(f"Count: {fit['count']:d}; status: {fit['status']}")
print(f"xi: {fit['xi']:.4g}; beta: {fit['beta']:.4g}")

Output

Count: 1; status: insufficient count
xi: nan; beta: nan

SpeedFit¶

An immutable record returned by fit_speed_models. Fields are name, law (frozen SciPy distribution), parameters (number estimated), log_likelihood, aic, ks_statistic, ks_pvalue, and boundary. The last field is empty for an interior fit, or names the GIG boundary law. Reported p-values are uncorrected for fitting. Parameters of law follow SciPy’s conventions; in particular inverse Gaussian shape is μ/κ\mu/\kappaμ/κ and scale is κ\kappaκ for physical mean μ\muμ and shape κ\kappaκ.

fit_speed_models¶

fit_speed_models(sample)

Return an AIC-sorted tuple of SpeedFit records for Gaussian, Rayleigh, Weibull, Gamma, inverse Gamma, inverse Gaussian, and GIG. Input must be a one-dimensional vector of at least three finite positive observations and must not be constant. Locations of positive families are fixed at zero. Gaussian has two estimated parameters, Rayleigh one, GIG three, and the others two. Inverse Gamma is fitted through the Gamma MLE of reciprocals; the transformation’s Jacobian is independent of its parameters.

The GIG fit includes normalizable Gamma and inverse Gamma boundaries. An inward score test certifies a boundary maximum using concavity in natural parameters, as proved in the note. Otherwise SciPy’s interior optimizer must converge within 4,000 iterations and 8,000 evaluations, and its likelihood must match or beat both boundaries to within 10-7. This numerical branch does not certify a global optimum. The frozen interior law uses SciPy’s geninvgauss(p, b, scale=scale): the note’s canonical parameters are a=b/scalea=b/\mathrm{scale}a=b/scale and bcanonical=b scaleb_{\rm canonical}=b\,\mathrm{scale}bcanonical​=bscale.

Nonfinite diagnostics and optimizer failures raise. Large interior GIG samples may be slow because their CDF uses quadrature. GIG’s AIC retains the nominal three-parameter penalty on a boundary; its usual regular-model interpretation is not asserted there. KS uses the ordinary exact finite-nnn distribution for a specified continuous CDF, without adjusting for the estimated parameters. Very small p-values may underflow to zero.
