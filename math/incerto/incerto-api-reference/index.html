Python API

The installed distribution is xshi-math; these helpers are imported as xmath.incerto. Install the numerical and plotting extra with:

uv sync --extra incerto

The base xmath helpers require only NumPy. The Incerto extra adds SciPy and Matplotlib; graph generation uses NetworkX and PyYAML from the development group. Dataset fetching uses standard-library urllib. The Python modules contain the full signatures and docstrings; there is no separate Sphinx build. Browse the module sources for implementations and use local help() for the installed version.

ModuleEntry points and purpose
xmath.incerto.datasetsload_amazon_bookrank, load_nyc_dog_name_frequencies, load_sp500_prices; explicit local-cache and refresh helpers
xmath.incerto.distributionspareto_type1, double_pareto, hypsecant2, simple_normal_mixture, univariate_variance_gamma; SciPy-style distribution objects
xmath.incerto.estimatorshill_estimator (extreme-value index), hill_alpha_estimator (reciprocal exponent), hill_stability, pareto_mean_plugin, mean_excess, running_mean, max_to_sum_ratio
xmath.incerto.statsGaussian-calibrated dispersion_ratios, mean_absolute_deviation, median_absolute_deviation; normal and Student-t shoulder boundaries; empirical_survival_function (strict exceedance with ties) and lognorm_params_from_mean_and_variance
xmath.incerto.tail_diagnosticsregular_variation_ratio, iid_two_sum_tail, subexponential_sum_ratio; numerical calculations with support and integration checks
xmath.incerto.tail_classesbounded_spike_summary (population moments), log_survival_multiplier_ratio (log-domain tail ratios); used by the Prologue models
xmath.incerto.glossarypareto_tail_quantities (log survival, conditional means, tail contribution), pareto_normalized_maximum_cdf (exact iid maximum law); chapter 2 worked cases
xmath.incerto.lecture_riskrepeated_event_probability, survival_from_hazards, finite_payoff_mean, absorbing_resource_path, split_power_damage_logsf, block_failure_summary; chapter 3 worked models
xmath.incerto.finite_momentsnormal_mixture_log_density, normal_mixture_log_abs_survival, normal_mixture_absolute_moment, pareto_moment_estimator_summary, power_mean; finite-moment worked cases
xmath.incerto.figuresset_theme, style_axes, savefig; shared figure style and deterministic export helpers
xmath.incerto.power_lawspareto_product_logsf, pareto_truncated_moment, student_double_pareto_scales, q_exponential_logsf, entropy_log_constraint_example; chapter 5 worked cases
import numpy as np
from xmath.incerto.distributions import pareto_type1
from xmath.incerto.estimators import hill_alpha_estimator

rng = np.random.default_rng(20261017)
x = pareto_type1.rvs(2.5, size=1000, random_state=rng)
alpha_hat = hill_alpha_estimator(x, k=100)

The example is a simulation, not a guarantee about estimation accuracy. The Hill note states the model and threshold assumptions. Use help() on an imported function for argument validation, return types, and numerical limits.

The empirical examples link to committed demo scripts and static figures. Dataset loading does not fetch by default. The S&P method explains the deliberately absent financial cache. The separate Normix API remains maintained upstream; this educational package does not vendor Normix.
