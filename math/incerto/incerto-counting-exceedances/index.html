Counting exceedances

A finite-sample quantity¶

For finite real observations x1,…,xnx_1,\ldots,x_nx1​,…,xn​ with n≥1n\geq 1n≥1, define the fraction strictly above a finite threshold ttt by

S^n(t)=1n∑i=1n1{xi>t}.\widehat S_n(t)=\frac{1}{n}\sum_{i=1}^n\mathbf{1}\{x_i>t\}.Sn​(t)=n1​i=1∑n​1{xi​>t}.
(1)

Here ttt is the local name for the threshold uuu in the shared notation. S^n\widehat S_nSn​ describes the observations; Fˉ(u)=P(X>u)\bar F(u)=P(X>u)Fˉ(u)=P(X>u) describes a population law. The symbol SnS_nSn​ without a hat denotes a sample sum elsewhere.

The strict inequality matters when an observation equals the threshold. For (1,2,2,4)(1,2,2,4)(1,2,2,4) at t=2t=2t=2, only the last observation contributes, so the fraction is 1/41/41/4. Counting observations greater than or equal to 2 would give 3/43/43/4 and answer a different question.

What the count establishes¶

Each indicator is either zero or one, so 0≤S^n(t)≤10\leq\widehat S_n(t)\leq10≤Sn​(t)≤1. If s<ts<ts<t, every observation exceeding ttt also exceeds sss. Therefore S^n(t)≤S^n(s)\widehat S_n(t)\leq\widehat S_n(s)Sn​(t)≤Sn​(s). These statements follow directly from counting; they are exact finite-sample arguments.

The helper xmath.exceedance_fraction implements this convention. From a checkout, run uv run python demos/incerto/exceedances.py to obtain fractions 1, 1/41/41/4, and 0 at thresholds 0, 2, and 4. The observations are synthetic and fixed.

A zero count above 4 does not establish that a population cannot exceed 4. Inference about an unseen population requires sampling and modeling assumptions that this example deliberately leaves unspecified. The Normix sample instead starts with an explicitly defined random-variable model.

The calculation uses a fixed synthetic sample; it needs no external data.

What iid sampling adds¶

Now assume X1,…,XnX_1,\ldots,X_nX1​,…,Xn​ are iid from FFF, and fix a nonrandom threshold uuu. Put q=Fˉ(u)q=\bar F(u)q=Fˉ(u). (3)

These are exact finite-sample identities, proved by summing the indicators. For any fixed ε>0\varepsilon>0ε>0, Chebyshev’s inequality gives P(∣S^n(u)−q∣>ε)≤q(1−q)/(nε2)P(|\widehat S_n(u)-q|>\varepsilon)\le q(1-q)/(n\varepsilon^2)P(∣Sn​(u)−q∣>ε)≤q(1−q)/(nε2), which tends to zero. No moment assumption on XXX is needed: the indicators are bounded. This argument is pointwise in a fixed uuu; it proves neither a uniform-in-threshold theorem nor consistency of an unbounded payoff average.
