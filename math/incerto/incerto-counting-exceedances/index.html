Counting exceedances

A finite-sample quantity¶

For finite real observations x1,…,xnx_1,\ldots,x_nx1​,…,xn​ with n≥1n\geq 1n≥1, define the fraction strictly above a finite threshold uuu by

S^n(u)=1n∑i=1n1{xi>u}.\widehat S_n(u)=\frac{1}{n}\sum_{i=1}^n\mathbf{1}\{x_i>u\}.Sn​(u)=n1​i=1∑n​1{xi​>u}.
(1)

Here uuu is the threshold in the shared notation. S^n\widehat S_nSn​ describes the observations; Fˉ(u)=P(X>u)\bar F(u)=P(X>u)Fˉ(u)=P(X>u) describes a population law. The symbol SnS_nSn​ without a hat denotes a sample sum elsewhere.

The strict inequality matters when an observation equals the threshold. For (1,2,2,4)(1,2,2,4)(1,2,2,4) at u=2u=2u=2, only the last observation contributes, so the fraction is 1/41/41/4. Counting observations greater than or equal to 2 would give 3/43/43/4 and answer a different question.

What the count establishes¶

Each indicator is either zero or one, so 0≤S^n(u)≤10\leq\widehat S_n(u)\leq10≤Sn​(u)≤1. If s<us<us<u, every observation exceeding uuu also exceeds sss. Therefore S^n(u)≤S^n(s)\widehat S_n(u)\leq\widehat S_n(s)Sn​(u)≤Sn​(s). These statements follow directly from counting; they are exact finite-sample arguments.

Use exceedance_fraction, empirical_survival_function.

from xmath import exceedance_fraction
from xmath.incerto.stats import empirical_survival_function

sample = [1, 2, 2, 4]
fractions = [exceedance_fraction(sample, u) for u in (0, 2, 4)]
print("Fractions: [" + ", ".join(f"{v:.4g}" for v in fractions) + "]")
support, survival = empirical_survival_function(sample)
print("Support: [" + ", ".join(f"{v:.4g}" for v in support) + "]")
print("Strict survival: [" + ", ".join(f"{v:.4g}" for v in survival) + "]")

Output

Fractions: [1, 0.25, 0]
Support: [1, 2, 4]
Strict survival: [0.75, 0.25, 0]

Ties form one jump.

The same fixed-sample calculation is available as uv run python demos/incerto/exceedances.py.

A zero count above 4 does not establish that a population cannot exceed 4. Inference about an unseen population requires sampling and modeling assumptions that this example deliberately leaves unspecified. The Normix sample instead starts with an explicitly defined random-variable model.

The calculation uses a fixed synthetic sample; it needs no external data.

What iid sampling adds¶

Now assume X1,…,XnX_1,\ldots,X_nX1​,…,Xn​ are iid from FFF, and fix a nonrandom threshold uuu. Each indicator 1{Xi>u}\mathbf1_{\{X_i>u\}}1{Xi​>u}​ has mean Fˉ(u)\bar F(u)Fˉ(u) and variance Fˉ(u)(1−Fˉ(u))\bar F(u)(1-\bar F(u))Fˉ(u)(1−Fˉ(u)), since its square equals itself. Independence makes the cross-covariances zero. Consequently,

ES^n(u)=Fˉ(u),Var⁡(S^n(u))=Fˉ(u)(1−Fˉ(u))n.\begin{gathered} \mathbb E\widehat S_n(u)=\bar F(u),\\ \operatorname{Var}(\widehat S_n(u))=\frac{\bar F(u)(1-\bar F(u))}n. \end{gathered}ESn​(u)=Fˉ(u),Var(Sn​(u))=nFˉ(u)(1−Fˉ(u))​.​
(3)

These are exact finite-sample identities, proved by summing the indicators. For any fixed ε>0\varepsilon>0ε>0, Chebyshev’s inequality gives

P(∣S^n(u)−Fˉ(u)∣>ε)≤Fˉ(u)(1−Fˉ(u))nε2,P(|\widehat S_n(u)-\bar F(u)|>\varepsilon) \le\frac{\bar F(u)(1-\bar F(u))}{n\varepsilon^2},P(∣Sn​(u)−Fˉ(u)∣>ε)≤nε2Fˉ(u)(1−Fˉ(u))​,
(4)

which tends to zero. No moment assumption on XXX is needed: the indicators are bounded. This argument is pointwise in a fixed uuu; it proves neither a uniform-in-threshold theorem nor consistency of an unbounded payoff average.
