Cramér Exponential-Moment Condition

Statement¶

A random variable XXX satisfies a right-tail Cramér condition when there is some θ>0\theta>0θ>0 such that

E[eθX]<∞.\mathbb E[e^{\theta X}]<\infty.E[eθX]<∞.
(1)

For two-sided large-deviation statements, one usually asks for the moment generating function M(θ)=E[eθX]M(\theta)=\mathbb E[e^{\theta X}]M(θ)=E[eθX] to be finite in an open neighborhood of 0. Equivalently, the cumulant generating function Λ(θ)=log⁡E[eθX]\Lambda(\theta)=\log \mathbb E[e^{\theta X}]Λ(θ)=logE[eθX] is finite near zero, and the Cramér rate function is

I(x)=sup⁡θ{θx−Λ(θ)}.I(x)=\sup_\theta\{\theta x-\Lambda(\theta)\}.I(x)=θsup​{θx−Λ(θ)}.
(2)

We use the one-sided version when the question is upper-tail concentration; the classical two-sided Cramér large-deviation theorem requires stronger mgf control.

The condition gives the elementary Chernoff bound

P(X>x)≤e−θxE[eθX],\mathbb P(X>x)\le e^{-\theta x}\mathbb E[e^{\theta X}],P(X>x)≤e−θxE[eθX],
(3)

so the upper-tail probability is bounded above by an exponentially decaying function. Equivalently, Fˉ(x)=O(e−θx)\bar F(x)=O(e^{-\theta x})Fˉ(x)=O(e−θx) for that value of θ\thetaθ.

Here Fˉ(x)=P(X>x)\bar F(x)=\mathbb P(X>x)Fˉ(x)=P(X>x) is the survival function, E\mathbb EE is expectation, and θ\thetaθ is the exponential-tilting parameter. All symbols needed here are defined locally; see also Shared notation.

Thin-tail intuition¶

The Cramér condition is a thin-tail gate. If exponential moments exist, then exponential tilting, Chernoff bounds, and classical large-deviation rates have room to operate. If no positive exponential moment exists, those tools may give a false sense of security.

This is the clean contrast with Pareto-type fat tails. A regularly varying tail can have many finite ordinary moments, but multiplying by eθXe^{\theta X}eθX eventually overwhelms every power-law decay. Failure of the Cramér condition does not require infinite variance: it can also occur when both the mean and variance are finite.

Chernoff bound and examples¶

We prove the displayed Chernoff bound from Markov’s inequality. The right-tail and two-sided Cramér conditions are definitions or standard large-deviation hypotheses; the larger Cramér theorem is cited rather than proved here. The normal, exponential, and Pareto cases below are direct checks of the condition.

The Chernoff bound follows from Markov’s inequality applied to the nonnegative random variable eθXe^{\theta X}eθX:

P(X>x)=P(eθX>eθx)≤e−θxE[eθX].\begin{aligned} \mathbb P(X>x)&=\mathbb P(e^{\theta X}>e^{\theta x})\\ &\le e^{-\theta x}\mathbb E[e^{\theta X}]. \end{aligned}P(X>x)​=P(eθX>eθx)≤e−θxE[eθX].​
(4)

A standard normal random variable satisfies the two-sided version because E[eθX]=eθ2/2\mathbb E[e^{\theta X}]=e^{\theta^2/2}E[eθX]=eθ2/2 for all real θ\thetaθ. An exponential random variable with rate λ>0\lambda>0λ>0 has mgf λ/(λ−θ)\lambda/(\lambda-\theta)λ/(λ−θ) for θ<λ\theta<\lambdaθ<λ, so it also satisfies the two-sided neighborhood condition. Its positive exponential moments exist exactly for 0<θ<λ0<\theta<\lambda0<θ<λ.

For a Pareto Type I random variable,

E[eθX]=∫xm∞eθxαxmαx−(α+1) dx.\begin{aligned} &\mathbb E[e^{\theta X}]\\ &\quad=\int_{x_m}^{\infty} e^{\theta x}\alpha x_m^\alpha x^{-(\alpha+1)}\,dx. \end{aligned}​E[eθX]=∫xm​∞​eθxαxmα​x−(α+1)dx.​

For every θ>0\theta>0θ>0, the exponential factor dominates the polynomial decay, so the integral diverges. Thus Pareto tails fail the right-tail Cramér condition for every positive θ\thetaθ.

bernoulli_chernoff_log_bound returns the log upper bound, which remains useful when probabilities underflow.

import numpy as np
from scipy.stats import binom
from xmath.incerto.limits import bernoulli_chernoff_log_bound

for n in (20, 100, 1000):
    exact = binom.sf(int(np.ceil(.75*n))-1, n, .5)
    bound = np.exp(bernoulli_chernoff_log_bound(.5, .75, n))
    print(f"n={n}: exact={exact:.4g}, bound={bound:.4g}")

It does not generally assert P(Xˉn>x)/e−nI(x)→1P(\bar X_n>x)/e^{-nI(x)}\to1P(Xˉn​>x)/e−nI(x)→1. Our Bernoulli calculation needs only Markov, independence, and elementary optimization, not that general theorem.

Caveats¶

  • The condition is direction-specific unless the moment generating function is finite around both sides of zero.

  • Failure of the Cramér condition does not by itself prove regular variation or subexponentiality. A lognormal distribution has every positive polynomial moment finite but no positive exponential moment, so “all moments finite” is not enough for the Cramér condition.

  • Empirical samples cannot prove that an exponential moment exists; a finite sample always has a finite empirical exponential average.

  • Large-deviation results need more than the one-line condition here. This page records the gate and the thin-tail contrast, not the full theorem.
