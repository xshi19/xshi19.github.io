Redundancy, size, and decentralized exposure

Splitting exposure can change both the size of a loss and the chance of simultaneous losses. These are separate mechanisms. We compare systems with the same total exposure, explicitly specifying their response to a shock and their dependence. None of the calculations identifies a real institution’s failure law.

Intermediate cases can be represented by kkk independent equal-size blocks, with perfect dependence within each block. Replacing mmm by kkk in these formulas gives the total damage law. Adding nominal modules inside an unchanged block does not increase the number of independent risks. This is a finite dependence comparison, not a model of contagion dynamics.

Worked calculation and sources¶

Use split_power_damage_logsf, block_failure_summary.

import numpy as np
from xmath.incerto.lecture_risk import split_power_damage_logsf, block_failure_summary

for modules in (1, 16):
    log_tail = split_power_damage_logsf(4, alpha=1.5, power=2, modules=modules)
    print(f"modules={modules:d}: {np.exp(log_tail):.4g}")
for blocks in (1, 10):
    print(f"blocks={blocks:d}")
    for name, value in block_failure_summary(0.02, blocks).items():
        print(f"  {name}: {value:.4g}")
