Redundancy, size, and decentralized exposure

Splitting exposure can change both the size of a loss and the chance of simultaneous losses. These are separate mechanisms. We compare systems with the same total exposure, explicitly specifying their response to a shock and their dependence. None of the calculations identifies a real institution’s failure law.

Splitting a fixed input to a convex damage function¶

Convexity gives the comparison when the same response is applied in each module and the resulting damages add.

Equal marginals, different aggregate failures¶

The bounded Bernoulli model isolates the effect of dependence.

For m=10m=10m=10, q=0.02q=0.02q=0.02, independent total failure has probability 0.0210=1.024×10−170.02^{10}=1.024\times10^{-17}0.0210=1.024×10−17, while some loss has probability 1−0.9810≈0.1829271-0.98^{10}\approx0.1829271−0.9810≈0.182927. All these finite Bernoulli sums are bounded, even when dependent.

Adding nominal modules inside an unchanged block does not increase the number of independent risks in the block model above. This is a finite dependence comparison, not a model of contagion dynamics.

Worked calculation and sources¶

Use split_power_damage_logsf, block_failure_summary.

import numpy as np
from xmath.incerto.lecture_risk import split_power_damage_logsf, block_failure_summary

for modules in (1, 16):
    log_tail = split_power_damage_logsf(4, alpha=1.5, power=2, modules=modules)
    print(f"modules={modules:d}: {np.exp(log_tail):.4g}")
for blocks in (1, 10):
    print(f"blocks={blocks:d}")
    for name, value in block_failure_summary(0.02, blocks).items():
        print(f"  {name}: {value:.4g}")
