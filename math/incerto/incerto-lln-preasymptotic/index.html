Pre-Asymptotic LLN Behavior

Setup¶

This synthetic example plots running means

Xˉn=Snn\bar X_n=\frac{S_n}{n}Xˉn​=nSn​​
(1)

for iid Pareto Type I samples with xm=1x_m=1xm​=1. The target contrast is:

  • if α≤1\alpha\le1α≤1, LLN Failure Under Infinite Mean says Xˉn→∞\bar X_n\to\inftyXˉn​→∞ almost surely;

  • if α>1\alpha>1α>1, the finite-mean law of large numbers says Xˉn→α/(α−1)\bar X_n\to\alpha/(\alpha-1)Xˉn​→α/(α−1), but convergence can still be slow when α\alphaα is close to 1.

The symbols Xˉn\bar X_nXˉn​, SnS_nSn​, α\alphaα, and xmx_mxm​ follow the shared notation table.

What the simulation isolates¶

The simulation uses exact iid Pareto draws. It does not include dependence, threshold fitting, censoring, mixtures, or measurement error. That narrow setup is deliberate: it isolates why the theorem can be practically easy to underestimate even before empirical complications enter.

The inverse-transform representation is

X=(1−U)−1/α,U∼Uniform⁡(0,1).X=(1-U)^{-1/\alpha},\qquad U\sim \operatorname{Uniform}(0,1).X=(1−U)−1/α,U∼Uniform(0,1).
(2)

The distribution helper in xmath.incerto.distributions implements the same Pareto Type I law.

Running-mean paths¶

The left panel shows single running-mean paths at log-spaced checkpoints. The right panel summarizes repeated final sample means at several sample sizes.

Run python demos/incerto/lln_preasymptotic.py after installing xshi-math[incerto] to reproduce these static figures. The script records the sample sizes and random seeds where simulation is used.

For α≤1\alpha\le1α≤1, no finite theoretical mean exists. For α=1.3\alpha=1.3α=1.3, the finite mean exists, but large observations still create visible pre-asymptotic jumps and wide repeated-simulation bands.

Interpretation and caveats¶

  • One simulated path is not a proof and not an estimator of α\alphaα.

  • The plot uses log axes. This makes early and late behavior comparable, but it also visually compresses large jumps.

  • A path with α>1\alpha>1α>1 can look worse than a path with α≤1\alpha\le1α≤1 over a finite window if it happens to receive an unusually large early draw.

  • Real data adds threshold choice, dependence, measurement limits, and model uncertainty. The example isolates only the iid Pareto mechanism.
