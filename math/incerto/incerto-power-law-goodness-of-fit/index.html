Power-law goodness of fit and alternatives

A best-fitting power law can still fit badly. Two questions follow the exponent and threshold fit: how unusual is its discrepancy under a power-tail model, and does another tail family fit better? The first asks about absolute goodness of fit; the second compares specified alternatives. Neither can be answered by a straight-looking log-log plot.

We use iid positive observations, a full sample of size NNN, and n=ntailn=n_{\mathrm{tail}}n=ntail​ retained values xi≥u=xmin⁡x_i\ge u=x_{\min}xi​≥u=xmin​. As in the shared notation, α>0\alpha>0α>0 is the survival exponent. The local density exponent is a=α+1a=\alpha+1a=α+1; CSN uses its symbol α\alphaα for this aaa. All package alpha values below follow the survival convention.

Worked example

The tech layoffs example applies these methods to event counts and workforce log losses. The examples on this theory page remain synthetic.

A fitted-null bootstrap for the KS distance¶

Let (α^,u^)(\widehat\alpha,\widehat u)(α,u) be the fit obtained by minimizing the refitted KS distance over the declared candidate rule, and let DobsD_{\mathrm{obs}}Dobs​ be that minimum. A textbook KS p-value for a fully specified continuous CDF is inappropriate: the exponent and cutoff were learned from these same data. Discrete data also lack the continuous distribution-free KS reference law.

The semiparametric bootstrap of Clauset et al. (2009), §4.1, constructs a null population with an empirical body and a fitted power-law tail. For each of BBB independent replicates:

  1. Generate NNN independent observations. For each draw, choose the fitted tail with probability n/Nn/Nn/N and the body with probability 1−n/N1-n/N1−n/N.

  2. A tail draw follows the fitted continuous Pareto or discrete zeta law above u^\widehat uu. A body draw is sampled uniformly, with replacement, from the original observations strictly below u^\widehat uu.

  3. Fit the replicate from the beginning, including its own threshold search and exponent estimate. Use the same minimum tail count and candidate rule as before; an observed-value rule uses this replicate’s values.

  4. Calculate Db∗D_b^*Db∗​ against that replicate’s fitted model on its selected tail.

The tail count before refitting is binomial with parameters NNN and n/Nn/Nn/N. Fixing it at the observed count would define a different resampling experiment. If the body is empty, every draw comes from the fitted tail. The model leaves the body’s shape unspecified; it does not pretend the whole sample is Pareto.

We estimate the tail probability by

p^=1B∑b=1B1{Db∗≥Dobs}.\widehat p=\frac1B\sum_{b=1}^B \mathbf1\{D_b^*\ge D_{\mathrm{obs}}\}.p​=B1​b=1∑B​1{Db∗​≥Dobs​}.
(1)

The inclusive comparison records ties conservatively, particularly for integer data. The helper uses this empirical fraction, which can equal zero; zero means no exceedance in these BBB replicates, not a proven zero probability. Fitted-null bootstrap calibration is an approximation to the composite testing problem, not an exact finite-sample uniform-p theorem.

A small p-value rejects this power-tail fitting procedure at a chosen significance level. A large value means the observed discrepancy was not unusual in the fitted-null experiment. It neither proves a power law nor gives the probability that the hypothesis is true. Small tail samples can have little power to distinguish curved tails. Choosing a new candidate rule after seeing the p-value introduces another selection step.

How many replicates?¶

Conditional on the fitted null and data, the indicators are iid Bernoulli with some Monte Carlo target probability p∗p_*p∗​. Hence

Var⁡MC(p^)=p∗(1−p∗)B,se⁡MC(p^)≤12B.\begin{aligned} \operatorname{Var}_{\mathrm{MC}}(\widehat p) &=\frac{p_*(1-p_*)}{B},\\ \operatorname{se}_{\mathrm{MC}}(\widehat p)&\le\frac1{2\sqrt B}. \end{aligned}VarMC​(p​)seMC​(p​)​=Bp∗​(1−p∗​)​,≤2B​1​.​
(2)

Requiring this worst-case standard error to be at most ε\varepsilonε gives B≥1/(4ε2)B\ge1/(4\varepsilon^2)B≥1/(4ε2). This is a one-standard-error precision rule, not a guarantee of absolute error within ε\varepsilonε. For an approximate 95% margin, the corresponding normal calculation multiplies the requirement by 1.962. Near zero or one, a binomial interval is more informative than a plug-in standard error of zero. Increasing BBB reduces simulation noise; it does not repair model bias, dependence, or threshold-selection uncertainty in the original observations.

powerlaw_gof_bootstrap refits every replicate and fails explicitly if a fit fails. It does not discard difficult replicates. Here the small sample and B=39B=39B=39 keep the demonstration fast. Its worst-case Monte Carlo standard error is about 0.08, so these outputs are illustrations rather than precise testing decisions. We use sample_powerlaw to generate the synthetic tail.

Code
import numpy as np
from xmath.incerto.powerlaw import sample_powerlaw, powerlaw_gof_bootstrap

rng = np.random.default_rng(340)
x = rng.uniform(1, 3, 240)
tail = rng.random(x.size) < 0.4
x[tail] = sample_powerlaw(1.8, 3, int(tail.sum()), random_state=rng)
result = powerlaw_gof_bootstrap(x, replicates=39, min_tail=40, random_state=341)
fit = result["fit"]
print(f"xmin={fit['xmin']:.3f}; tail count={fit['n_tail']}")
print(f"KS={fit['ks']:.3f}; bootstrap p={result['p_value']:.3f}")
print(f"Worst-case Monte Carlo SE: {result['worst_case_mc_se']:.3f}")
print(f"Distinct refitted thresholds: {len(np.unique(result['xmins']))}")

Output

KS=0.066; bootstrap p=0.410

Compare normalized likelihoods on the same tail¶

Select a common threshold uuu and keep exactly the same observations for every comparison. If a candidate has unconditioned density g(x;θ)g(x;\theta)g(x;θ) and survival Gˉ(u;θ)\bar G(u;\theta)Gˉ(u;θ), its conditional tail density is

q(x;θ,u)=g(x;θ)Gˉ(u;θ),x≥u,ℓ(θ;u)=∑i=1nlog⁡g(xi;θ)−nlog⁡Gˉ(u;θ).\begin{aligned} q(x;\theta,u)&=\frac{g(x;\theta)}{\bar G(u;\theta)},\qquad x\ge u,\\ \ell(\theta;u)&=\sum_{i=1}^n\log g(x_i;\theta)\\ &\quad-n\log\bar G(u;\theta). \end{aligned}q(x;θ,u)ℓ(θ;u)​=Gˉ(u;θ)g(x;θ)​,x≥u,=i=1∑n​logg(xi​;θ)−nlogGˉ(u;θ).​
(3)

This display assumes a continuous law. For an integer law the denominator is Pθ(X≥u)P_\theta(X\ge u)Pθ​(X≥u), and numerator and denominator must both use counting measure. Do not compare log probability masses with log densities, or let one model discard observations that another model must explain.

Conditioning changes the fit, not merely its reported likelihood. For example, fitting an ordinary lognormal to the retained values and subtracting a tail normalizer afterward is generally not maximum likelihood for the conditional model, because that normalizer depends on the parameters.

The following continuous alternatives all have support [u,∞)[u,\infty)[u,∞) after conditioning. Each parameter is fitted on that same retained sample.

Lognormal¶

Let μ∈R\mu\in\mathbb Rμ∈R and σ>0\sigma>0σ>0 be the location and standard deviation of the untruncated log variable. With Φˉ=1−Φ\bar\Phi=1-\PhiΦˉ=1−Φ,

z(x)=(log⁡x−μ)/σ,qLN(x)=exp⁡[−z(x)2/2]xσ2π Φˉ(z(u)).\begin{aligned} z(x)&=(\log x-\mu)/\sigma,\\ q_{\mathrm{LN}}(x)&=\frac{\exp[-z(x)^2/2]} {x\sigma\sqrt{2\pi}\,\bar\Phi(z(u))}. \end{aligned}z(x)qLN​(x)​=(logx−μ)/σ,=xσ2π​Φˉ(z(u))exp[−z(x)2/2]​.​
(4)

The denominator accounts for the omitted lower part of the parent lognormal. A broad lognormal can mimic a power tail over a finite interval. In limiting parameter sequences its conditional density can approach a Pareto law, so regular, distinguishable interior fits cannot simply be presumed.

Exponential¶

For rate λ>0\lambda>0λ>0, conditioning an exponential above uuu gives

qE(x)=λe−λ(x−u),λ^=[1n∑i=1n(xi−u)]−1.\begin{aligned} q_{\mathrm E}(x)&=\lambda e^{-\lambda(x-u)},\\ \widehat\lambda&=\left[\frac1n\sum_{i=1}^n(x_i-u)\right]^{-1}. \end{aligned}qE​(x)λ​=λe−λ(x−u),=[n1​i=1∑n​(xi​−u)]−1.​
(5)

This rate is determined by excesses above the cutoff. A mean of the raw retained values gives the wrong rate for this conditional model.

Stretched exponential / Weibull¶

Write y=x/uy=x/uy=x/u, shape k>0k>0k>0, and β=(u/τ)k>0\beta=(u/\tau)^k>0β=(u/τ)k>0, where τ\tauτ is the parent Weibull scale. Then

qW(x)=kβuyk−1exp⁡[−β(yk−1)].q_{\mathrm W}(x) =\frac{k\beta}{u}y^{k-1}\exp[-\beta(y^k-1)].qW​(x)=ukβ​yk−1exp[−β(yk−1)].
(6)

The name stretched exponential usually refers to 0<k<10<k<10<k<1; the implementation fits the full Weibull family, including the exponential case k=1k=1k=1. At fixed kkk, differentiating the conditional log likelihood gives

β^(k)=[1n∑i=1n(yik−1)]−1.\widehat\beta(k)= \left[\frac1n\sum_{i=1}^n(y_i^k-1)\right]^{-1}.β​(k)=[n1​i=1∑n​(yik​−1)]−1.
(7)

Profiling out β\betaβ leaves a one-dimensional numerical shape fit. Comparing Weibull against exponential is a nested problem; comparing Weibull against Pareto requires the non-nested conditions discussed below.

Power law with exponential cutoff¶

The cutoff law is sometimes called a truncated power law. Here “cutoff” means an exponential damping factor, not a hard finite upper endpoint. Define the dimensionless cutoff b=λub=\lambda ub=λu, with λ>0\lambda>0λ>0, and

C(a,b)=∫1∞z−ae−b(z−1) dz,qC(x)=(x/u)−ae−b(x/u−1)uC(a,b).\begin{aligned} C(a,b)&=\int_1^\infty z^{-a}e^{-b(z-1)}\,dz,\\ q_{\mathrm C}(x)&=\frac{(x/u)^{-a}e^{-b(x/u-1)}}{uC(a,b)}. \end{aligned}C(a,b)qC​(x)​=∫1∞​z−ae−b(z−1)dz,=uC(a,b)(x/u)−ae−b(x/u−1)​.​
(8)

For b>0b>0b>0, any real aaa gives an integrable density. At b=0b=0b=0, normalization requires a>1a>1a>1 and C(a,0)=1/(a−1)C(a,0)=1/(a-1)C(a,0)=1/(a−1), recovering the pure Pareto law. The coefficient a−1a-1a−1 in an interior cutoff fit is not its asymptotic survival exponent: the exponential factor eventually dominates. All positive moments of an interior cutoff law exist.

The normalizing integral is part of the optimization. Omitting it rewards arbitrary changes of scale in the purported density and invalidates a likelihood-ratio comparison.

Non-nested comparisons: sign, normalization, and p-value¶

For two fitted conditional densities evaluated on the same nnn observations, let

di=log⁡q^1(xi)−log⁡q^2(xi),R=∑i=1ndi,dˉ=R/n,sd2=1n∑i=1n(di−dˉ)2,ZV=Rn sd.\begin{aligned} d_i&=\log\widehat q_1(x_i)-\log\widehat q_2(x_i),\\ R&=\sum_{i=1}^n d_i,\qquad \bar d=R/n,\\ s_d^2&=\frac1n\sum_{i=1}^n(d_i-\bar d)^2,\\ Z_V&=\frac{R}{\sqrt n\,s_d}. \end{aligned}di​Rsd2​ZV​​=logq​1​(xi​)−logq​2​(xi​),=i=1∑n​di​,dˉ=R/n,=n1​i=1∑n​(di​−dˉ)2,=n​sd​R​.​
(9)

Positive RRR favors model 1; negative RRR favors model 2. The normalized statistic ZVZ_VZV​ is sometimes also called normalized RRR. Under the null that the two pseudo-true models have equal expected log likelihood, Vuong’s non-nested result gives an asymptotic standard normal reference and the two-sided p-value

pV=2{1−Φ(∣ZV∣)}.p_V=2\{1-\Phi(|Z_V|)\}.pV​=2{1−Φ(∣ZV​∣)}.
(10)

We cite the fitted-model asymptotic result in Vuong (1989) rather than prove it. Its conditions include iid sampling, regular interior parameter estimation, distinguishable non-nested models, and a finite, strictly positive variance of the limiting per-observation contrast. The heuristic central limit argument applies to that limiting contrast; fitted scores sharing estimated parameters are not themselves independent observations.

These qualifications matter for heavy tails. Against an exponential, a Pareto log-likelihood contrast contains a term proportional to XXX. Under an exact Pareto generator, its variance is infinite if α≤2\alpha\le2α≤2, and even its expectation can fail for α≤1\alpha\le1α≤1. A finite array of scores cannot verify the population moment assumptions. Overlap, a nearly vanishing sds_dsd​, or an optimizer drifting toward a family boundary also requires different analysis.

A small pVp_VpV​ and the sign of RRR distinguish relative fit under those conditions. They do not establish that the preferred model fits well in an absolute sense. A large pVp_VpV​ leaves the comparison unresolved; it does not establish equivalence. The statistic below uses the unpenalized log likelihoods, not an AIC or BIC adjustment.

If uuu was selected on the same data, the fixed-threshold reference theorem does not automatically cover that selection. Report such p-values as conditional approximations, or use an independent threshold choice or a simulation design that repeats the selection procedure. Several pairwise tests add a multiplicity issue; a collection of unadjusted p-values is not a single calibrated family-selection decision.

fit_tail_model supplies fitted per-observation log likelihoods, and likelihood_ratio_test computes the comparison. This example fixes u=1u=1u=1 before sampling. The Pareto generator has α=3\alpha=3α=3, so the exponential contrast has finite variance. Both samples have 2500 observations; each comparison uses the entire sample.

Code
import numpy as np
from xmath.incerto.powerlaw import (
    sample_powerlaw, fit_tail_model, likelihood_ratio_test,
)
rng = np.random.default_rng(350)
samples = {
    "Pareto": sample_powerlaw(3, 1, 2500, random_state=rng),
    "Exponential": 1 + rng.exponential(size=2500),
}
for name, x in samples.items():
    pl = fit_tail_model(x, 1, "powerlaw")
    exp = fit_tail_model(x, 1, "exponential")
    lr = likelihood_ratio_test(pl["loglik"], exp["loglik"])
    print(f"{name}: R={lr['R']:.2f}, Z={lr['normalized_R']:.2f}, p={lr['p_value']:.3g}")

Output

Pareto: R=233.67, Z=4.31, p=1.6e-05
Exponential: R=-206.54, Z=-11.82, p=2.93e-32

The alternative fitter currently supplies continuous densities. Exact discrete power-law fits and bootstrap checks are available, but an integer-data comparison needs separately normalized discrete alternatives. Treating a continuous density as a probability at an integer is not that extension. Numerical multi-start optimization also cannot certify a global maximum; check the returned status, parameter boundaries, and sensitivity to the model.

The nested cutoff comparison needs its own calibration¶

The pure power law is the λ=0\lambda=0λ=0 boundary of the cutoff family. If both optimizations find their maxima, the larger family cannot have lower maximized likelihood. With model 1 the pure law and model 2 the cutoff law,

R=ℓPL−ℓC≤0,TLR=2(ℓC−ℓPL)=−2R.\begin{aligned} R&=\ell_{\mathrm{PL}}-\ell_{\mathrm C}\le0,\\ T_{\mathrm{LR}}&=2(\ell_{\mathrm C}-\ell_{\mathrm{PL}})=-2R. \end{aligned}RTLR​​=ℓPL​−ℓC​≤0,=2(ℓC​−ℓPL​)=−2R.​
(11)

The sign therefore gives no evidence by itself for a cutoff. Under an ordinary regular interior restriction with one extra parameter, Wilks’ reference is χ12\chi_1^2χ12​. Here λ≥0\lambda\ge0λ≥0 and the null sits at its boundary. With one regular constrained direction and interior identifiable nuisance parameters, a common reference is the mixture

12δ0+12χ12,\tfrac12\delta_0+\tfrac12\chi_1^2,21​δ0​+21​χ12​,
(12)

where δ0\delta_0δ0​ is a point mass at zero. This boundary result is cited from Self & Liang (1987), §3, Case 5. For a positive observed statistic its upper-tail p-value is half the χ12\chi_1^2χ12​ upper tail; at zero the inclusive upper-tail probability is one.

That mixture is not a universal cutoff test. The cutoff score at the Pareto null involves X−EXX-\mathbb E XX−EX; ordinary finite-information regularity already fails when the null tail has α≤2\alpha\le2α≤2. An estimated threshold, other boundary parameters, or failure to find a likelihood maximum introduces further issues. A null simulation calibrated for the actual fitting procedure is preferable when the reference-law assumptions are unsupported: simulate under the null, repeat every fitted step, and compare refitted LR statistics. The KS goodness-of-fit bootstrap above is a different statistic and does not supply this nested LR p-value.

The helper’s nested=True option returns TLRT_{\mathrm{LR}}TLR​ and leaves its p-value uncalibrated by default. Selecting calibration="chi2" or calibration="boundary" explicitly asserts the corresponding conditions; the software cannot verify them from two score arrays.

import numpy as np
from xmath.incerto.powerlaw import fit_tail_model, likelihood_ratio_test

x = 2 + np.random.default_rng(370).exponential(size=600)
pure = fit_tail_model(x, 2, "powerlaw")
cutoff = fit_tail_model(x, 2, "truncated_powerlaw")
lr = likelihood_ratio_test(pure["loglik"], cutoff["loglik"], nested=True)
print(f"Nested LR statistic: {lr['statistic']:.2f}")
print(lr["status"])

Output

Nested LR statistic: 55.81
nested statistic requires calibration

What to report¶

Report the observational unit and independence assumptions, continuous or integer support, candidate-threshold rule, selected threshold, retained count, exponent convention, and uncertainty procedure. For goodness of fit include the KS discrepancy, replicate count, seed, Monte Carlo precision, and failures. For each comparison include the common tail, conditional likelihood family, optimization status, signed RRR, and the reason a chosen p-value calibration is applicable. Preserve inconclusive outcomes instead of turning every comparison into a winner.
