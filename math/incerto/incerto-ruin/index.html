Ruin and repeated exposure

An absorbing state changes which future payoffs a path can receive. Let TTT be the first ruin time, taking values in {1,2,…}∪{∞}\{1,2,\ldots\}\cup\{\infty\}{1,2,…}∪{∞}; the process stays ruined after TTT. The probability law PPP and expectation E\mathbb EE follow the shared notation.

Independent repeated exposure¶

Proposition 1 (Independent exposure with constant ruin probability)

Let independent trials each fail with probability q∈(0,1]q\in(0,1]q∈(0,1], and let T∈{1,2,…}∪{∞}T\in\{1,2,\ldots\}\cup\{\infty\}T∈{1,2,…}∪{∞} be the first failure time. For every integer N≥0N\ge0N≥0,

An absorbing barrier can also make the order of additive payoffs matter.

Proposition 3 (Equal increment sums with different ruin outcomes)

Start with resource 3, add successive increments while resources remain positive, and set resources permanently to zero on first reaching a nonpositive value. The increments (−4,4)(-4,4)(−4,4) give the path (3,0,0)(3,0,0)(3,0,0); the reversed increments (4,−4)(4,-4)(4,−4) give (3,7,3)(3,7,3)(3,7,3). Both increment sums are zero.

Proof 6

In the first order, 3−4=−13-4=-13−4=−1 triggers absorption immediately. In the second, 3+4=73+4=73+4=7 and 7−4=37-4=37−4=3 remain positive. The increment sum is −4+4=0-4+4=0−4+4=0.

Worked calculation and source scope¶

Use survival_from_hazards, absorbing_resource_path.

from xmath.incerto.lecture_risk import survival_from_hazards, absorbing_resource_path

survival = survival_from_hazards([0.02] * 3)
print("Survival through step 3: [" + ", ".join(f"{v:.4g}" for v in survival) + "]")
for increments in ([-4, 4], [4, -4]):
    path = absorbing_resource_path(3, increments)
    print(f"{increments}: [" + ", ".join(f"{v:.4g}" for v in path) + "]")
