S&P 500 tail diagnostics

For closing index levels Pt>0P_t>0Pt​>0, define a daily log loss by

ℓt=−log⁡(Pt/Pt−1).\ell_t=-\log(P_t/P_{t-1}).ℓt​=−log(Pt​/Pt−1​).
(1)

The Hill estimator uses only ℓt>0\ell_t>0ℓt​>0; zero-return and rising-price days are excluded. Here PtP_tPt​ denotes an index level, not the probability law PPP in the shared notation.

Reproducible method¶

Run python demos/incerto/sp500_tail.py. Without data, it prints an availability message and exits successfully. With data, it reports the sample dates, loss count, Hill estimates, and mean excess across thresholds. It does not publish index data or produce figures during the site build.

import numpy as np
from xmath.incerto.datasets import load_sp500_prices
from xmath.incerto.estimators import hill_alpha_estimator, mean_excess

prices = load_sp500_prices(fetch=False)
dates, losses = prices.negative_log_returns()
for k in (25, 50, 100, 200, 400):
    if k < len(losses):
        print(k, hill_alpha_estimator(losses, k))
if len(losses) >= 20:
    thresholds = np.quantile(losses, [0.8, 0.9, 0.95])
    print(mean_excess(losses, thresholds, min_exceedances=5))

The empirical survival estimate at sorted losses ℓ(i)\ell_{(i)}ℓ(i)​ is 1−i/(n+1)1-i/(n+1)1−i/(n+1). Inspect it on log-log axes alongside the Hill curve and mean excess. Report the number of observations, threshold, kkk, sample window, and transformation with each estimate. Threshold selection discusses the bias and sampling variation that change as the threshold moves.

Interpretation and caveats¶

A straight segment in a survival plot does not establish a Pareto tail. The peaks-over-threshold theorem requires a domain-of-attraction assumption; it does not verify that assumption for equity returns. Daily losses are dependent and volatility-clustered, whereas a basic Hill calculation treats observations as iid. These diagnostics also use price-index closes rather than dividend-adjusted total returns.

No numerical conclusion about S&P losses is asserted here without a dated local sample. A fitted exponent is conditional on that sample and threshold; it is not a forecast of the next daily loss.
