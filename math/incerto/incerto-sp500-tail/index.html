S&P 500 tail diagnostics

For closing index levels Pt>0P_t>0Pt​>0, define a daily log loss by

ℓt=−log⁡(Pt/Pt−1).\ell_t=-\log(P_t/P_{t-1}).ℓt​=−log(Pt​/Pt−1​).
(1)

The Hill estimator uses only ℓt>0\ell_t>0ℓt​>0; zero-return and rising-price days are excluded. Here PtP_tPt​ denotes an index level, not the probability law PPP in the shared notation.

The chapter-10 diagnostics reuse this cache for aggregation, drawdowns, moment concentration, records, and gain/loss comparisons. The pipeline note adds a frozen chronological risk-estimator comparison.

Data source and window¶

The observed calculation uses Yahoo Finance ^GSPC daily Close, fetched locally on 2026-10-30 with auto_adjust=False Yahoo Finance, 2026. It is a price index, not total return: dividends are not reinvested. The default return window is 1928-01-03 through 2026-10-29, comprising 24,824 log returns. The cache has 24,825 closes, beginning with the 1927-12-30 anchor. The supplied 2026-10-30 intraday row is dropped. Of the returns, 11,493 are losses, 13,018 are gains and 313 are zero. The Hill and mean-excess calculations below condition on loss days.

The full available history retains early crises and 1987. This choice also pools different regimes and historical index coverage, so the estimates describe this sample rather than a stationary population. Only derived statistics and plots are distributed. The raw cache is not redistributed under Yahoo’s source-use terms Yahoo, 2026. Site rendering uses the recorded outputs and SVGs; it does not fetch or read prices.

Reproducible method¶

Use load_sp500_prices, hill_alpha_estimator, mean_excess, and PriceSeries.negative_log_returns. The Yahoo writer handles the optional download separately from this calculation.

Code: run this calculation
import numpy as np
from xmath.incerto.datasets import load_sp500_prices
from xmath.incerto.estimators import hill_alpha_estimator, mean_excess

prices = load_sp500_prices(fetch=False, end_date="2026-10-29")
_, losses = prices.negative_log_returns()
print(f"Return window: {prices.date[1]} to {prices.date[-1]}")
print(f"Closes: {len(prices.close)}; returns: {len(prices.close) - 1}; loss days: {len(losses)}")
for k in (25, 50, 100, 200, 400):
    if k < len(losses):
        print(f"Hill k={k}: alpha={hill_alpha_estimator(losses, k):.2f}")
thresholds = np.quantile(losses, [0.8, 0.9, 0.95])
result = mean_excess(losses, thresholds, min_exceedances=5)
for u, excess, count in zip(result["threshold"], result["mean_excess"], result["exceedances"]):
    print(f"threshold={100 * u:.2f}% log, mean excess={100 * excess:.2f}% log, exceedances={count:.0f}")

Interpretation and caveats¶

A straight segment in a survival plot does not establish a Pareto tail. The peaks-over-threshold theorem requires a domain-of-attraction assumption; it does not verify that assumption for equity returns. Neither independence nor stationarity is established for this pooled history. Treating loss days as iid would ignore their chronological spacing and volatility changes. No iid standard errors or moment-existence verdicts are attached to these fits. A fitted exponent above four at one threshold and below two at another cannot settle the existence of the population variance or fourth moment.

A fitted exponent is conditional on this dated sample and threshold; it is not a forecast of the next daily loss. The half-window diagnostics expose further sensitivity to which decades are included.
